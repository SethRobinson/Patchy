# Tool palette: layout, flyouts, cycle hotkeys, and icons

The tool palette toolbar built by `MainWindow::build_tool_palette()`: tool order, the color cluster and overflow behavior, flyout groups and their Shift+letter cycle commands, and the tool icon art rules. Tool behaviors live in [tools.md](tools.md); hotkey registration rules in [ui-conventions.md](ui-conventions.md).

## Layout and overflow

- Built imperatively in `MainWindow::build_tool_palette()` (main_window_actions_tool_palette.cpp, the tool-palette phase of `create_actions()`); order is the construction order, in separator-delimited clusters: select (Move, Marquee, Lasso, Wand, Crop), paint (Brush, Eraser, Gradient+Fill), retouch (Stamp, Healing, Detail, Toning), draw/type (Pen Tools, Path Tools, Shapes, Type), view (Pick, Hand, Zoom). The Pen Tools flyout sits directly before the Path Tools flyout because drawing and adjusting paths alternate constantly. The Pen stays separate from the path-select tools (a flyout hides the tool you switch to most); the anchor tools live under the Pen because Photoshop users look for them there. See [vector-commands.md](vector-commands.md).
- Below the tools, an expanding spacer pins the color cluster to the bottom edge, ordered FG swatch, BG swatch, Default Colors (D), Swap Colors (X), separator, Quick Mask. That order is deliberate for vertical overflow: QToolBar hides items tail-first into the extension button, so a short window loses Quick Mask first, then X and D, and the swatches last. The palette width is a 43 px minimum (`kToolPaletteCollapsedMinWidth`), never fixed, because clicking the extension arrow expands the bar into extra columns by temporarily widening it; a fixed width clamps that into a clipped sliver (see the standing rule in [ui-conventions.md](ui-conventions.md)). The expansion is a sticky toggle: stock Qt collapses it half a second after the pointer leaves the bar, so `ToolPaletteExpansionLock` swallows Leave while the extension button is checked, and picking a palette item leaves it open (an auto-collapse there eats the first click of the Zoom button's double-click-for-100%). While it is open, `ToolPaletteExpansionReservation` raises the bar's minimum width to the measured expanded width so the main-window layout reserves the extra columns and the canvas shrinks instead of being overlaid; each pass releases the minimum, re-measures, and re-pins so Qt can drop back to fewer columns when the window grows. The bar closes on an arrow re-click, or automatically once the window is tall enough that nothing overflows. Coverage: `ui_tool_palette_overflow_hides_quick_mask_before_swatches`, `ui_tool_palette_extension_button_expands_palette`, `ui_tool_palette_expansion_sticky_after_tool_pick`, `ui_tool_palette_expanded_zoom_double_click_sets_actual_pixels`, `ui_tool_palette_expansion_collapses_when_window_fits_again`.
- Tools sharing a slot go through the shared `create_flyout_tool_action` + `configure_tool_flyout` lambdas. Eleven flyouts in menu order (the first member is the default unless marked): Marquee / Elliptical Marquee; Lasso / Magnetic Lasso; Magic Wand / Quick Select; Gradient / Fill; Clone / Pattern Stamp; Healing Brush (J) / Spot Healing / Patch ([healing.md](healing.md)); Smudge / Mixer Brush / Blur / Sharpen; Dodge / Burn / Sponge; Pen (P) / Add Anchor / Delete Anchor / Convert Point; Path Select (A) / Direct Select; Line / Rectangle (default, U) / Ellipse / Polygon / Custom Shape. The flyout swaps the button's default action on each member action's `triggered`, which also covers hotkey activation. Tools whose gestures the name does not explain also carry a two-line tooltip (`tool_tooltip_detail_source`) and a status-bar activation hint (`tool_activation_hint_source`).
- Every flyout button sets the `toolFlyout` Qt property; the app stylesheet keys the corner-triangle `::menu-indicator` and its sizing on `QToolButton[toolFlyout="true"]`, so a new flyout only needs the property (via `configure_tool_flyout`), not a new QSS selector. Coverage: `ui_stamp_and_gradient_flyouts_swap_tools`.
- A flyout opens three ways: press-and-hold (`QToolButton::DelayedPopup`; the delay is `SH_ToolButton_PopupDelay` from `InteractionHintsStyle` in `src/app/main.cpp`, 200 ms instead of Qt's 600), a left double-click, or a right-click (`configure_tool_flyout` installs a `ToolFlyoutEventFilter` that calls `showMenu()` for both: Qt otherwise routes the double-click pair's second press back to `mousePressEvent` and restarts the hold timer, and a right press would otherwise reach the toolbar's own context menu). The first click of the pair still selects the default tool. The flyout menu is the only group UI: a persistent tool-group bar beside the palette was rejected (Seth's decision). Coverage: `ui_tool_flyout_double_click_opens_menu`, `ui_tool_flyout_right_click_opens_menu`.
- **Shift+letter cycles a flyout** (GitHub issue 45, Photoshop's convention): `configure_tool_flyout` also registers one "Cycle <Group> Tools" command per flyout (`tools.cycle.marquee`, `.lasso`, `.wand`, `.gradient`, `.stamp`, `.healing`, `.detail`, `.tone`, `.pen`, `.path_select`, `.shape`; object names `toolCycle...Action`; category `tools`) on Shift plus the group's letter (Shift+M, L, W, G, S, J, R, O, P, A, U), listed in the flyout menu after a separator. It selects the member after the active tool when the active tool is in the group, otherwise the member after the one the button shows, wrapping, so every member is reachable by key. The members past the first ship unbound because Qt fires neither of two actions sharing a sequence; a saved user override that puts Shift+<letter> back on a member wins the sequence and suppresses the cycle default (`ui_tool_cycle_yields_to_member_override`). The plain letter still selects the primary tool. Coverage: `ui_tool_cycle_hotkeys_walk_each_flyout`, `ui_photoshop_shortcuts_are_registered`.

## Icons

- Original SVGs at `src/ui/icons/tool-*.svg` (32x32, `#dce2eb` strokes, at most one non-load-bearing `#74c0ff` accent). Generic metaphors, no Photoshop geometry, so the license stays clean.
- QtSvg renders a Tiny-1.2 subset only, and a typo'd qrc alias renders EMPTY silently. Review with `patchy_ui_visual_tests.exe ui_tool_palette_icons` (writes contact-sheet artifacts, checks per-icon coverage + pairwise distinctness).
- Clone keeps the classic rubber-stamp silhouette; Pattern Stamp is deliberately a different silhouette (stamp knob over a large checkerboard tile) because a small in-base detail was indistinguishable from Clone at the palette's 20px render size. Keep any future pair of related tools distinct in SILHOUETTE, not just in accent color. The healing flyout follows the same rule: bandage (Healing Brush), circle with burst ticks (Spot Healing), rotated stitched square (Patch). The pen flyout: nib drop (Pen), a curve with a hollow anchor plus a + or - accent (Add/Delete Anchor), a corner whose anchor sprouts a handle (Convert Point).
