# Layers panel blend and opacity row

The row above the layer list: the blend mode box, Opacity and Fill. In a narrowing panel the box narrows first, then Opacity and Fill drop their labels, and only a row too wide even then wraps. Parent: [layer-panel.md](layer-panel.md). How the row wraps in a narrow column: [right-docks.md](right-docks.md#narrow-layers-panel); the Show Fill field option: [layer-panel-row-options.md](layer-panel-row-options.md).

## Blend and opacity row

Dragging the "Opacity:" or "Fill:" prefix scrubs the value (`install_prefix_scrub`, [ui-conventions-dialogs.md](ui-conventions-dialogs.md#options-bar)): the drag ends with `editingFinished`, so `finish_pending_layer_opacity_edit` closes it as one undo entry; a prefix click focuses the field, number selected. Combos from `add_blend_mode_items` also step with Left/Right. Panel blend changes merge into one undo entry until a pause or another history change (`ui_layer_blend_mode_steps_coalesce_into_one_undo_entry`). Pass Through is offered first, for folders only (`set_blend_mode_pass_through_offered` per active layer, `BlendModeMenu::Folder` in Blending Options), and never lands on a selected non-folder (#235). `refresh_layer_thumbnails` re-syncs each row's mode and opacity line (`layer_row_details_text`, #236). The blend row, the lock/filter row and the footer wrap in a narrow column (#96, #199; [right-docks.md](right-docks.md)).

The blend mode box narrows before the row wraps (#693). Its natural width is its longest mode name plus a scroll bar's width and 8 px; `update_right_dock_minimum_width` hands that and a minimum (the default mode's name, the arrow and 4 px: 64 px offscreen in English) to `PopupAwareComboBox::set_shrink_widths`, and `WrappingControlRowLayout::set_shrink_widget` lets the row take the difference before it wraps. English offscreen: the row is 351 px at natural widths and 265 px at the narrowest, so the three controls share a line with their labels from the 367 px opening width down to a 277 px column (the box is 133 px at 346 px, 80 px at 293 px); below that Opacity and Fill drop their labels (next paragraph). Opacity and Fill never narrow below their measured widths. A name the box cannot show ends in "..." (`displayed_text`; the box paints it, since the style would clip the label mid-letter), the tooltip then adds the whole name on a second line (`hover_text`), and the open list is widened to its entries (`fit_combo_popup_to_entries`), so every mode reads whole there. At the opening width English is unchanged. A language whose Opacity and Fill prefixes leave less than the minimum beside them drops the prefixes there (Russian: 363 px against 355 px of room; it wrapped before the follow-up); Polish, which wrapped at the opening width, now holds one line with the box narrowed (307 px). `ui_layer_blend_row_stays_on_one_line_in_narrow_panel`.

Opacity and Fill drop their labels before the row wraps (the #693 follow-up). The "Opacity: " and "Fill: " prefixes are the fields' labels, set through `set_toolbar_spinbox_prefix` (dialog_utils.hpp), never `setPrefix`. `WrappingControlRowLayout` measures the row both ways from the font (`toolbar_spinbox_width_with_prefix`, whichever state shows): where the labelled row does not fit one line with the blend mode box at its narrowest and the row without labels does, every grow widget drops its prefix (`set_toolbar_spinbox_prefix_dropped`), a hidden Fill included, so the two never disagree; at the first width the labelled row fits, both return. Rules:

- **No feedback, so no hysteresis.** The state follows from the row's width alone and changes none of the sizes the row reports: `minimumSize`, `sizeHint`, `comfortable_width` and the wrapped lines all count the labels. One pixel either side of the threshold gives the same answer every time; never decide by toggling the prefix and measuring the widget.
- **The freed room** goes to the blend mode box first (back toward its natural width), then to the fields as spare width.
- **Wrapping keeps the labels.** A row too wide for one line even without labels wraps as before (#96, #199), labels shown: dropping them there would gain nothing. At the stock fonts no language reaches that: the row without labels (196 px at its narrowest in English) is narrower than the layer list's minimum (256 px), under which the panel scrolls sideways. So the three controls share a line at every width, and with Show Fill field off the labelled Opacity fits beside the box at every width in English.
- **Widths, English offscreen:** labels down to a 277 px column, none from 276 px to the 268 px compact width. A longer translation drops sooner; Russian opens without labels.
- **Tooltips** name the fields at every width ("Opacity", "Fill": the MainWindow strings that already existed, bound with `bind_tooltip`).
- **Scrubbing.** Without its prefix the field scrubs like every options-bar field (a drag while it is not being edited; a click edits, number selected), and the empty room left of the right-aligned number is the always-scrubbing handle the prefix was (`ScrubFieldHandle::over_prefix`).
- **Language switches** record the new labels through `set_toolbar_spinbox_prefix`, which shows them only while they are not dropped, re-measure, and ask for a layout; the row then drops or restores for the new widths.

`ui_layer_blend_row_drops_labels_before_wrapping` (Fill shown and hidden; the wrap with wide-floored fields), `ui_layer_blend_row_wraps_in_narrow_panel` (Russian, Polish, English).

Opacity and Fill reach the panel's right edge (issue 680 follow-up 2): they are the row's grow widgets (`WrappingControlRowLayout::add_grow_widget`), counted at their measured width (`kToolbarSpinboxStretchProperty` makes `configure_toolbar_spinbox`'s width a minimum instead of fixed, for these two only), and each line hands its spare width to the grow widgets on it, in equal shares with the rounding pixel on the last. So the last field of every line ends where the filter row and the layer list end, Fill shown or hidden, on one line or wrapped. Spare width exists only once the blend mode box is back at its natural width; the box never takes any, and on a wrapped line of its own it keeps its natural width. `ui_layer_blend_row_fields_reach_the_panel_edge`.

While the list is open (#367, `PopupAwareComboBox`), the highlighted mode shows on every selected layer (`preview_layer_blend`, coalesced, async render) with no history entry, session revision or row refresh. Closing restores the modes before Qt reports a choice, which commits one entry; a history change, edit snapshot, or another document or selection closes the list and reverts (`ui_layer_blend_list_*`).
