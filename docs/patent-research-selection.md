# Patent research: automatic selection (Select Subject, Object Selection)

Claim-level record behind the "Automatic selection" bullet in [legal-constraints.md](legal-constraints.md) (review dated 2026-10-11; claims read on Google Patents; expiry dates are Google's adjusted estimates). Design: [ai-selection.md](ai-selection.md).

## Active patents and what each independent claim needs

- **US 10192129 B2** (Adobe, priority 2015-11-18, to about 2036-08): interactive deep selection. A network trained on images, masks, user indicators and distance maps; positive/negative clicked pixels; a distance map from the indicators to every pixel; image plus indicators plus distance map into the network. SAM encodes prompt coordinates positionally, with no distance map.
- **US 11314982 B2** (same family, to about 2037-01): a first user indicator inside the object and a second outside it, a network turning the image plus both indicators into a probability map, a mask from it. No distance map required. A positive and a negative point in one SAM solve would have every element of it. **Never send a negative point.**
- **US 11568627 B2** (same family, to about 2037-06): two user inputs of different modalities (regional clicks, boundary box, language) through separate input channels of one multi-modal network. **One prompt type per solve: a box or a point, never both.**
- **US 12626496 B2** (same family, granted 2026-05-12): training with distance maps. Running a pretrained model does not include that element.
- **US 11676279 B2** (Adobe, priority 2020-12-18, to about 2041-02): an initial segmentation into one encoder, a user indicator converted to a distance map into a second encoder, a decoder producing the updated segmentation. **Never feed a previous mask back (SAM `mask_input` stays zero) and never refine a Select Subject result through the network.**
- **US 11244195 B2** (Adobe, priority 2018-05-01, to about 2040-05) and continuation **US 12591950 B2** (to about 2040-12): run a salient network on a reduced copy, crop the region it finds, run the network again, merge to full resolution; the continuation adds deciding whether more refinement is needed and re-processing sub-regions. **Select Subject is one pass over the whole image, upsampled once: no network-located crop, no second pass.** BiRefNet's internal fixed-grid patches are not a network-located region.
- **US 10460214 B2** (Adobe, to about 2038-01): a mobile device choosing a real-time or a static salient network by live feed versus still image.
- **US 11107219 B2, US 11631234 B2, US 11468550 B2, US 11055566** (Adobe, priority 2019, to about 2039): text queries, class labels, and choosing among detectors or known/unknown-class paths. **One fixed model per command, no class labels, no routing.**
- **US 11972569 B2** (Adobe, to about 2041-03): two segmentation models, merged overlapping masks, routing to specialist networks. **US 12260557 B2** (Adobe, to about 2043-06): per-region class-driven masking pipelines merged. A single fixed model has neither.
- **US 2023/0129341 A1** (Adobe application 17/584,233, priority 2021-10-23; notice of allowance 2026-04-21, issue fee paid 2026-07-14; on 2026-10-20 Google Patents still showed it pending while USPTO full-text search listed patent 12731259 under its title, application number and claims unconfirmed): preliminary masks for several objects, an input over one object shows its mask, an input over another swaps to it. **No hover preview and no mask-everything-in-advance.** Watch item: confirm 12731259 is this application and read its allowed claims.
- **US 10068361 B2** (Adobe, to about 2035-11): a cursor over an indefinite boundary defines a matting band and adds soft selection when the input ends (the Refine Edge brush). **US 11593948 B2** (Adobe, to about 2041-05): a matting network driven by a guidance mask with two matte layers fused (claim 11 through a boundary-uncertainty mask). **No edge-refinement brush and no learned matting stage.**
- **US 10698588 B2** (Adobe, "Combined selection tool", to about 2037-09): automatically toggling between a coarse graph-cut mode and a level-set refinement mode from whether Add or Remove is active and whether the input lands inside or outside the current selection boundary. Narrower than "any input-driven algorithm switch"; still avoid switching mechanisms on mode plus click position.
- **US 8050498** (live coherent selection, to 2029-11-03): already binding for Quick Select; Object Selection likewise computes nothing for display during the drag.

## Matting models for Select Subject (review 2026-10-12)

Question: may Select Subject use a BiRefNet matting model (true per-strand alpha) instead of, or beside, BiRefNet general? Candidate: `ZhengPeng7/BiRefNet_lite-matting` (MIT, Swin-T, 1024 input, 44.36 M parameters like the current general model; no official ONNX, so Patchy would export it in eval mode and check the graph has one output and no `conv_ms_spvn`/`gdt_convs_pred` nodes). The Swin-L matting models (BiRefNet-matting 1024, BiRefNet_HR-matting 2048, dynamic-matting) are legally the same but estimated 3x to 6x (1024) and far more (2048) CPU time and memory.

- **US 12051225 B2** (Adobe, filed 2021-10-28, granted 2024-07-30, 331 days PTA, so to about 2042-09; claims read on the USPTO scan). Claims 1 and 10 need a trimap. **Independent claim 16 does not**: patch-based encodings from transformer layers of a transformer encoder; a decoder of additional layers and upsampling layers; modified encodings from the additional layers; the alpha matte from both through upsampling layers joined to the additional layers by skip connections. Dependent claim 20 describes Swin-style self-attention blocks with patch merging. BiRefNet's architecture (Swin encoder, lateral 1x1 blocks, skip-connected upsampling decoder) is close to these elements for the general and matting weights alike (the spec defines an alpha matte broadly as per-pixel opacity), so the BiRefNet commands stay out of releases until a further review. Published earlier work with transformer encoders plus skip-connected dense decoders predates October 2021 (TransUNet, Swin+UperNet, DPT, SegFormer, Swin-Unet). The pending continuation US 2024/0362825 A1 could broaden. **Open item**; the only alternative design is a CNN-only encoder, not reviewed.
- **US 12347116 B2** (continuation of US 11593948, to about 2041-06): no guidance mask, but needs a first and second alpha matte from different network layers combined into a refined matte, then a third matte. BiRefNet's inference graph has one output head; its gradient attention gates are feature gates, never mattes. **Never export or use side outputs, average stage outputs, or fuse a boundary band.**
- Absent from a single trimap-free pass (claims read): US 10255681 / US 10657652 (trimap input), US 11004208 / US 11880977 (user location, mask, trimap), US 11308628 (trimap patches), US 11393100 / US 11651477 (crop and trimap networks), US 12008734 (boundary color density), US 11875510 (point-wise refining blocks), US 12236610 (alpha-range classification), US 12217435 (Canva, two trimaps), US 12205299 (ByteDance, video), US 12536669 (Orbbec, background image input). **US 11335004** (uncertain-pixel re-classification), **US 12020400** (patch refinement of an upsampled mask) and **US 12282987** (branches plus error-map patch refinement) forbid any band, tile or patch refinement step.
- Ways to offer it: replacing the model, or a user-chosen preference or separate command, are believed clear (no "Auto", no choice from content, size or confidence). Running both models and merging approaches US 11972569 and the matte-fusion claims; general first and matting on a band or crop has the elements of US 11593948 claim 11, US 11335004, US 12020400 and US 11244195; feeding one model's output into the other (a 4th channel, BiRefNet's `Refiner`/`RefUNet`) is a guidance mask (US 11593948, US 11676279). All forbidden.
- Foreground color estimation (removing the background tint from soft hair pixels): Germer et al. 2020 multi-level estimation (pymatting, MIT) has no patent found; Levin closed-form matting (US 7692664) lapsed. **Adobe US 8379972 B1** ("Color decontamination for image compositing", filed 2009-11-30, about 2029-11 plus any PTA) claims not read; read them before shipping any decontamination.
- Training data of the matting weights includes PPM-100 (CC BY-NC-SA mattes) and request-only sets (Distinctions-646, HIM2K, Human-2k); how dataset terms bear on weights is unsettled, unverified.

## EfficientViT-SAM, zoom-to-box and the model choice (review 2026-10-12)

- **Model.** Object Selection's High Quality model is EfficientViT-SAM XL0 (MIT Han Lab, Apache-2.0, weights from the project's Hugging Face repository at commit a2f0c592). It replaces only SAM's image encoder (EfficientViT: convolutions plus ReLU linear attention) and keeps SAM's prompt encoder and mask decoder: two-way transformer and transposed-convolution upscaling over the final embedding only, no skip connections from encoder stages. The US 12051225 claim 16 element "upsampling layers joined to the additional layers by skip connections" is therefore absent, as for MobileSAM. Its ONNX decoder has no mask input at all (US 11676279's mask input cannot occur through it). Prompts are unchanged: one box or one positive point. Patchy exposes the decoder's four masks and picks by predicted IoU exactly as for MobileSAM. Trained on SA-1B like MobileSAM, so the training-data posture is unchanged.
- **Rejected candidates.** SAM 2.1 (Hiera) feeds high-resolution encoder stages into the decoder's upsampling, and HQ-SAM fuses early ViT features into its mask head; both approach US 12051225 claim 16 and are out until a further review. HQ-SAM also trains on sets with non-commercial terms. CorridorKey: CC BY-NC-SA-based license with a no-redistribution term, and a guidance-mask matting design (US 11593948).
- **Zoom-to-box.** A box much smaller than the image is encoded from its own region: the box grown by a fixed margin (15% of its longer side, at least 64 px), widened to at least 384 px, clamped to the image, skipped when that covers 80% of it (`sam_box_region`). One encode of that region, one decode of the box. US 11244195 / US 12591950 need a network-located region (a salient network's output) and a second pass; here the region is the user's own box by fixed geometry, never a model output, and nothing is re-run. US 12020400 and US 11335004 refine patches or uncertain pixels of an existing mask; nothing here refines a mask.
- **Model choice.** Standard (MobileSAM, bundled) or High Quality (downloaded once on request). Which runs is the user's Model setting plus whether the download exists, never image content, size or confidence: not the routing or model selection of US 11107219, US 11631234, US 11972569 or US 12260557. Embeddings decode only with their own model's decoder; results are never merged across models.

## Assessment of the current design

- Select Subject: one BiRefNet pass over the whole image, sigmoid matte upsampled once, combined by plain boolean. Clear of the iterative-salient, detector, query and routing claims.
- Object Selection: one decoder run per release from one box (labels 2, 3) or one positive point (label 1 plus SAM's padding point, label -1). Clear of US 10192129 (no distance map), US 11314982 (no negative indicator), US 11568627 (one modality), US 11676279 (no mask feedback). Picking the output with the highest predicted IoU (among the three alternatives for a point, among all four for a box) chooses among outputs of one decoder run for one prompt, not among algorithms or models; believed clear, not yet reviewed in depth.
- The image encoder runs on the first press with no prompt and nothing displayed; the hover-preview application needs preliminary masks shown on hover, which never exist here.

## Prior art notes

GrabCut (2004) established box-to-segmentation. Single-pass CNN saliency (MDF 2015, DHSNet 2016, DSS 2017) predates US 11244195. Xu et al., "Deep Interactive Object Selection" (CVPR 2016) is the 10192129 family's own publication and postdates its priority, so it is not prior art against it. DEXTR (2018) and SAM (2023) only predate later filings.
