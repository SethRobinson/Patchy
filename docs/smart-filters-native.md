# Native Smart Filters: descriptors, FEid cache, render calibration

Calibration record for Photoshop-native Smart Filter authoring and rendering. Read this before touching src/psd smart-filter descriptor I/O or src/filters/smart_filter_renderer.cpp. Model and UI rules live in [smart-objects.md](smart-objects.md).
Conventions: "PS" = Adobe Photoshop 2026/27.8, the installed ground truth; every rule is pinned by PS COM captures unless noted. Fixtures named `photoshop-*` live in `test-fixtures/psd/`; `local-test-fixtures/` is machine-local. The COM workflow lives in [ps-compat.md](ps-compat.md).

## Native Smart Filters

- The per-layer SoLd descriptor owns `filterFX` (class `filterFXStyle`); `filterFXList` is in application order (PS displays the last filter at the top). Each item is class `filterFX` with enable state, `hasoptions`, integer `filterID`, `blendOptions` (percent opacity + stringID `BlnM`), foreground/background RGB, and `Fltr`. Classes/ids and keys:
  - Gaussian Blur `GsnB`/0x47736E42, High Pass `HghP`/0x48676850, Median `Mdn `/0x4D646E20: `Rds ` as `#Pxl` unit float, fractional preserved.
  - Dust & Scratches `DstS`/0x44737453: integer `Rds ` (1..500; max read off PS's dialog, 2026-07-30) then `Thsh` (0..255); object name `Dust & Scratches`, entry `Nm  ` literally `Dust && Scratches...`.
  - Surface Blur stringID `surfaceBlur`/854: unit-double `Rds ` (1..100) then integer `Thsh` (2..255).
  - Unsharp Mask `UnsM`/0x556E734D: `Amnt` % (1..500), `Rds ` #Pxl (0.1..1000), `Thsh` (0..255).
  - Motion Blur `MtnB`/0x4D746E42: integer `Angl` (-360..360), unit-pixel `Dstn` (1..999).
  - Plastic Wrap `PlsW`/0x506C7357: integers `Hghl` (0..20), `Dtl ` (1..15), `Smth` (1..15).
  - Mosaic: one `ClSz` #Pxl double, entry `Mosaic...`; dialog 2..200 px.
  - Emboss: entry `Emboss...`, plain integers `Angl, Hght, Amnt`; accepted -360..360 / 1..100 / 1..500 (Amount 0 stays destructive-only; PS's minimum is 1).
  - Box Blur stringID `boxblur`/843: `Rds ` #Pxl double, floored for render; values through 2000 accepted (UI max unpinned).
  - Radial Blur `RdlB`: `Amnt` int (1..100), `BlrM` (`Spn `/`Zm  `), `BlrQ` (`Drft`/`Gd  `/`Bst `). NO blur center is stored, so native mapping only at the default 50/50 center (quality samples 8/16/32); Spin renders, Zoom stays preview-locked.
  - Add Noise `AdNs`: `Dstr` (`Unfr`/`Gsn `), `Nose` #Prc (0.1..400), `Mnch` bool, `FlRs` seed integer stored verbatim.

  Whole-stack `enab`, `validAtPosition`, `filterMaskEnable`, `filterMaskLinked`, `filterMaskExtendWithWhite` live on the root. Action Manager stores out-of-range values verbatim, so authoring gates must enforce the dialog ranges; entries carry trailing `comp`/`compInfo`.
- **FEid/FXid cache** associates records with SoLd `placed`, not source `Idnt`; PS writes outer version 3 (spec defines 1-3). Record: `u64 bodyLength`, Pascal `placed` uuid, record version 1, `u64 cacheLength`, cache planes, optional shared filter mask. Cache metadata: rect, depth, max channel count, then max+2 written/length/data slots; masks are 8-bit raw or PackBits. PS places 0-3 zero alignment bytes after each record inside the declared payload; that padding is NOT part of `bodyLength` and must not be confused with tagged-block padding. The reader also accepts pre-0.20 Patchy's unpadded multi-record shape and preserves it.
- Patchy authors the PS 27.8 shape directly: canonical `filterFXStyle` objects in the verified key order, one shared version-3 FEid record covering the full document (depth 8, max channel 24, PackBits RGB in slots 0/1/2, alpha in slot 25, shared mask separate). The cached planes are the UNFILTERED placed Smart Object, not the filtered preview. Existing supported descriptors are patched at known leaves so unmodeled keys and charID/stringID forms survive.
- **Render semantics** (kernels and exact math in src/filters/smart_filter_renderer.cpp; filters embed in the transparent document-space FEid canvas, sample past it by nearest edge, and alpha-trim after growth):
  - Gaussian Blur: separable, premultiplied alpha; PS byte-rounds the horizontal pass before the vertical. Calibrated at 23 radii, 0.1..8 px; the measured kernels differ from a true Gaussian (notably radius 0.5, bytes `[55,145,55]`); radius 4.5 keeps sub-byte tails (the native one-level outer halo). Measured table through 8 px, deterministic recursive approximation above.
  - High Pass: same radius semantics on STRAIGHT RGB, `clamp(source - separately byte-rounded Gaussian + 128)`; alpha/bounds unchanged; hidden RGB kept at alpha 0; kernels pinned at 10/11/12 px, recursive above 12. One primitive serves direct, gallery, and native paths.
  - Median: keeps bounds; upper median per RGBA channel over a square edge-clamped window, radius `floor(Rds)` min 1; alpha independent. Zero-alpha pixels borrow straight RGB from the nearest visible source (squared Euclidean; ties favor lower row, then right column); partially transparent keeps its own RGB; all-transparent keeps hidden RGB.
  - Dust & Scratches: bounds/alpha byte-identical; Median's candidate with the same extension, replacing all three channels only when the max absolute RGB difference exceeds `Thsh`.
  - Surface Blur: radius `max(1, floor(Rds + 0.5))`; sample weight `max(0, 5*Thsh - 2*abs(v - c))`, quotient rounds to nearest, ties to even; RGB uses Median's extension, alpha the weights directly.
  - Unsharp Mask: keeps bounds/alpha; its low-pass kernel differs from Gaussian's at equal radius; truncate `detail * Amnt / 100`, remove `Thsh` from the magnitude, add the remainder back (scale-first order pinned).
  - Motion Blur: one fixed premultiplied line at the entered angle, distance d = d+1 even taps; weights quantized for determinism.
  - Plastic Wrap: deterministic integer height-field render; bounds/alpha byte-exact; Patchy-original pixels, no byte-identity claim.
  - Mosaic, Emboss, Box Blur, Radial Blur (Spin), Add Noise: pinned byte-equal to the corresponding destructive filters (Box Blur above radius 12 via an exact integer sliding window; Radial Blur about the content center; Add Noise deterministic position-hashed from the seed, Patchy's own noise, not PS's).
- Blur Gallery: native Tilt-Shift = stringID `blurbTransform`, filter id 712, entry `Blur Gallery...`; gallery descriptors can hold multiple widgets and are not calibrated. Patchy's Lens Blur, Iris Blur, and Tilt-Shift stay destructive/gallery-only; imported gallery stacks stay byte-preserved and preview-locked; a direct or mixed gallery recipe rasterizes rather than authoring or partially executing `blurbTransform`; no private PSD block is invented.
- Stack semantics: each nondefault blend/opacity result source-over composites onto the previous result; Normal 100% replaces. The shared document-space mask applies once to the completed stack. Editing rebuilds the unfiltered placed/warped raster before running the stack; placement, warp, Edit Contents, linked refresh, Relink, and Replace Contents regenerate the FEid cache. The first supported filter seeds the mask from the exact selection alpha; no selection writes an all-white mask. Editable native masks cap at 64 megapixels; larger imported records stay preview-locked.
- Untouched SoLd and FEid/FXid payloads stay byte-exact. Rekeying duplicates changes only the Pascal `placed` id and rebuilds the envelope; the cloned FEid record must sit directly AFTER its source, and the cloned layer needs a fresh native `lyid` (PS rejects wrong cache order and merges duplicate lyids); Patchy allocates the next unused native id independently of runtime `LayerId`. Unknown versions, malformed bounds/lengths, trailing row data, unsupported depth/compression, missing associations, and duplicate `placed` matches fail closed; any opaque FEid/FXid block disables association and mutation store-wide. If ANY `filterFXList` entry is unsupported the whole stack stays preview-locked; never execute a known prefix over PS's baked preview. No private fallback block.
- Fixture inventory: [smart-objects.md](smart-objects.md). PS ignores written `filterMaskLinked=true`; Patchy preserves the flag but keeps that stack preview-locked.
