# Native Smart Filters: descriptors, FEid cache, render calibration

CMYK FEid caches contain inverted C/M/Y/K in slots 0..3 and alpha in slot 25
(Photoshop captures `cmyk-render/smart-filtered-{8,16}.psd`). Photoshop's 16-bit
capture uses 16-bit ZIP-predicted planes, preserved but preview-locked; Patchy's
authored caches use the supported 8-bit form. Imported records retain their source
profile in session metadata through rekeying, mask edits and clipboard copies.
CMYK saves convert rebuilt sRGB cache planes with that document's profile while
preserving the remaining slots and exact mask tail. Unchanged native caches are
emitted verbatim. The layer preview converts separately at the parent depth;
neither conversion alters the live document or undo snapshots.

Calibration record for Photoshop-native Smart Filter authoring and rendering. Read this before touching src/psd smart-filter descriptor I/O or src/filters/smart_filter_renderer.cpp. Model and UI rules live in [smart-objects.md](smart-objects.md).
Conventions: "PS" = Adobe Photoshop 2026/27.8, the installed ground truth; every rule is pinned by PS COM captures unless noted. Fixtures named `photoshop-*` live in `test-fixtures/psd/`; `local-test-fixtures/` is machine-local. The COM workflow lives in [ps-compat.md](ps-compat.md).

## Native Smart Filters

- The per-layer SoLd descriptor owns `filterFX` (class `filterFXStyle`); `filterFXList` is in application order (PS displays the last filter at the top). Each item is class `filterFX` with enable state, `hasoptions`, integer `filterID`, `blendOptions` (percent opacity + stringID `BlnM`), foreground/background colors, and `Fltr`. Classes/ids and keys:
  - Gaussian Blur `GsnB`/0x47736E42, High Pass `HghP`/0x48676850, Median `Mdn `/0x4D646E20: `Rds ` as `#Pxl` unit float, fractional preserved.
  - Dust & Scratches `DstS`/0x44737453: integer `Rds ` (1..500; max read off PS's dialog) then `Thsh` (0..255); object name `Dust & Scratches`, entry `Nm  ` literally `Dust && Scratches...`.
  - Surface Blur stringID `surfaceBlur`/854: unit-double `Rds ` (1..100) then integer `Thsh` (2..255).
  - Unsharp Mask `UnsM`/0x556E734D: `Amnt` % (1..500), `Rds ` #Pxl (0.1..1000), `Thsh` (0..255).
  - Motion Blur `MtnB`/0x4D746E42: integer `Angl` (-360..360), unit-pixel `Dstn` (1..2000). PS's render clamps above 2000 (2000, 2001 and 5000 render identically) while its Smart Filter stores any value verbatim.
  - Plastic Wrap `PlsW`/0x506C7357: integers `Hghl` (0..20), `Dtl ` (1..15), `Smth` (1..15).
  - Mosaic: one `ClSz` #Pxl double, entry `Mosaic...`; dialog 2..200 px.
  - Emboss: entry `Emboss...`, plain integers `Angl, Hght, Amnt`; accepted -360..360 / 1..100 / 1..500 (Amount 0 stays destructive-only; PS's minimum is 1).
  - Box Blur stringID `boxblur`/843: `Rds ` #Pxl double, floored for render; values through 2000 accepted (UI max unpinned).
  - Radial Blur `RdlB`: `Amnt` int (1..100), `BlrM` (`Spn `/`Zm  `), `BlrQ` (`Drft`/`Gd  `/`Bst `). NO blur center is stored, so native mapping only at the default 50/50 center (quality samples 8/16/32); Spin and Zoom both render (`zoom` flag; BlrM re-emits the stored method).
  - Add Noise `AdNs`: `Dstr` (`Unfr`/`Gsn `), `Nose` #Prc (0.1..400), `Mnch` bool, `FlRs` seed integer stored verbatim.
  - Parameterless classics (`kParameterlessSmartFilters` in core/smart_filter.hpp): Blur `Blr `, Blur More `BlrM`, Sharpen `Shrp`, Sharpen More `ShrM`, Sharpen Edges `ShrE`, Invert `Invr`, Average `Avrg`, filterID = that charID. No `Fltr` object; `hasoptions` false (older Photoshop wrote true for Invert; kept as read); `Nm  ` is the plain name ("Blur More"); key order Nm, blendOptions, enab, hasoptions, FrgC, BckC, filterID. Such an id beside a `Fltr` fails closed. Filter > Blur > Blur, Blur More, Average and Filter > Sharpen > Sharpen More author these entries on a Smart Object without a dialog. An imported Shrp renders and round-trips, but Patchy's own Sharpen command (a stronger kernel with an Amount) never authors it, and Image > Adjustments > Invert keeps its refusal.
  - Smart Sharpen (stringID `smartSharpen`, id 887), legacy case only ([patent-research-smart-sharpen.md](patent-research-smart-sharpen.md)): exactly the keys `presetKind`, `useLegacy` true, `Amnt` #Prc (1..500), `Rds ` #Pxl (0.1..1000), `noiseReduction` #Prc 0 and `blur` (`blurType`) `GsnB`; any other key (`moreAccurate`, the Shadows fade `sdwM`, a Highlights fade) locks it. PS renders that byte for byte as Unsharp Mask at the same Amount and Radius with threshold 0 (probes on noise, ramps, impulses and mixed alpha at 100%/2 px and 250%/0.7 px), so it renders through Patchy's Unsharp Mask and shares its partially transparent gap (below); edits patch only `Amnt`/`Rds `, and no menu command authors one. Every other descriptor (CC mode, Noise Reduction above 0, Lens or Motion removal, `moreAccurate`, a Shadows or Highlights fade) stays preview-locked and byte-preserved; legacy mode ignores Noise Reduction in PS, but the modeled case still requires 0.
  - Preview-locked by decision (October 2026): Reduce Noise (`denoise`, id 796: per-channel `amount`/`edgeFidelity`, `colorNoise`, `sharpen`, `removeJPEGArtifact`); its edge-adaptive noise reduction needs a claim-level review first. Lens Blur cannot be a Smart Filter at all (PS refuses it on a Smart Object).
  - Offset, Maximum, Minimum, Custom, Fragment, Crystallize, Pointillize, Mezzotint, Fibers (table-described; Pixelate, Render, Noise and Other captures): [smart-filters-pixelate-render.md](smart-filters-pixelate-render.md).
  - Image > Adjustments (Levels, Curves, Hue/Saturation, Brightness/Contrast, Color Balance, Channel Mixer, Exposure, Posterize, Threshold, Photo Filter, Black & White): `Fltr` is the command's action descriptor, verbatim; [smart-filters-adjustments.md](smart-filters-adjustments.md).
  - Filter Gallery `GEfc`/0x47456663, entry `Filter Gallery...`: one effect sits inline (`GEfk` enum `GEft` = the effect id, then the effect's own keys); two or more sit in `GEfs`, a list of `GEfc` objects and the root's only key. An effect applied from its own menu item stores its own class with the same keys (Plastic Wrap `PlsW`) and PS renders the two forms alike (October 2026 capture `photoshop-smart-filter-gallery.psd`). Patchy models only effects it renders: Plastic Wrap, every key required (an action that omits them gets PS defaults, not captured). Effects run in order through the Plastic Wrap renderer; edits patch the integers in place; Patchy never adds, removes or reorders effects or authors a `GEfc`. Any other effect, key or shape keeps the stack preview-locked. A single-effect entry edits through its effect's dialog; a multi-effect entry renders and saves but opens no dialog.

  Entry `FrgC`/`BckC` hold the colors in the model they were picked in: `RGBC` usually, `HSBC` or `LbCl` when the picker was in HSB or Lab (a Ripple capture, October 2026). Import reads all three as RGB; an HSB or Lab color stays verbatim on save while its RGB reading is unchanged.
  Whole-stack `enab`, `validAtPosition`, `filterMaskEnable`, `filterMaskLinked`, `filterMaskExtendWithWhite` live on the root. Action Manager stores out-of-range values verbatim, so authoring gates must enforce the dialog ranges; entries carry trailing `comp`/`compInfo`.
- **FEid/FXid cache** associates records with SoLd `placed`, not source `Idnt`; PS writes outer version 3 (spec defines 1-3). Record: `u64 bodyLength`, Pascal `placed` uuid, record version 1, `u64 cacheLength`, cache planes, optional shared filter mask. Cache metadata: rect, depth, max channel count, then max+2 written/length/data slots; masks are 8-bit raw or PackBits. PS places 0-3 zero alignment bytes after each record inside the declared payload; that padding is NOT part of `bodyLength` and must not be confused with tagged-block padding. The reader tells PS's aligned chain from pre-0.20 Patchy's unpadded one by walking every following record in each dialect to the payload end: after an odd-length record the unpadded read lands in the padding and still yields a small plausible length (a file with several filtered Smart Objects went opaque that way). The reader also accepts pre-0.20 Patchy's unpadded multi-record shape and preserves it.
- Patchy authors the PS 27.8 shape directly: canonical `filterFXStyle` objects in the verified key order, one shared version-3 FEid record covering the filter canvas (depth 8, max channel 24, PackBits RGB in slots 0/1/2, alpha in slot 25, shared mask separate). The cached planes are the UNFILTERED placed Smart Object, not the filtered preview, and stay 8-bit in 16/32-bit documents (smart-object contents and Smart Filters render at 8 bits; [high-bit-depth.md](high-bit-depth.md)). Existing supported descriptors are patched at known leaves so unmodeled keys and charID/stringID forms survive.
- **Render semantics** (kernels and exact math in src/filters/smart_filter_renderer.cpp, with Box Blur, Radial Blur, Emboss and Mosaic bodies shared with the destructive filters through src/filters/filter_kernels.cpp; filters embed in the transparent FEid canvas, which is the document united with the placed bounds (`smart_filter_canvas_bounds`; PS keeps a layer's off-canvas pixels as filter input and its FEid cache covers that rectangle, while Patchy's authored mask keeps its document rectangle; `ui_smart_filter_canvas_unites_document_and_placed_bounds`), sample past it by nearest edge, and alpha-trim after growth):
  - Gaussian Blur: separable, premultiplied alpha; PS byte-rounds the horizontal pass before the vertical. Calibrated at 23 radii, 0.1..8 px; the measured kernels differ from a true Gaussian (notably radius 0.5, bytes `[55,145,55]`); radius 4.5 keeps sub-byte tails (the native one-level outer halo). Measured table through 8 px, deterministic recursive approximation above.
  - High Pass: same radius semantics on STRAIGHT RGB, `clamp(source - separately byte-rounded Gaussian + 128)`; alpha/bounds unchanged; hidden RGB kept at alpha 0; kernels pinned at 10/11/12 px, recursive above 12. One primitive serves direct, gallery, and native paths.
  - Median: upper median per RGBA channel over a square window edge-clamped at the filter canvas (transparent beyond the placed bounds, so alpha erodes at a layer's edges; the past-edge capture pins it), radius `floor(Rds)` min 1; alpha independent, so the result never grows past the placed bounds. Zero-alpha pixels borrow straight RGB from the nearest visible source (squared Euclidean; ties favor lower row, then right column); partially transparent keeps its own RGB; all-transparent keeps hidden RGB. Open gap: on the soft-edged past-edge source 308 pixels differ in RGB from PS (up to 81 levels, most partially transparent, 213 well inside the document), so that rule is incomplete; alpha is exact.
  - Dust & Scratches: bounds/alpha byte-identical; Median's candidate with the same extension, replacing all three channels only when the max absolute RGB difference exceeds `Thsh`.
  - Surface Blur: radius `max(1, floor(Rds + 0.5))`; sample weight `max(0, 5*Thsh - 2*abs(v - c))`, quotient rounds to nearest, ties to even; RGB uses Median's extension, alpha the weights directly.
  - Unsharp Mask: keeps bounds/alpha; its low-pass kernel differs from Gaussian's at equal radius (radius 2.5 has its own measured byte kernel); truncate `detail * Amnt / 100`, remove `Thsh` from the magnitude, add the remainder back (scale-first order pinned). Calibrated on opaque content. Open gap on partially transparent sources (the Smart Sharpen capture, October 2026): PS also sharpens alpha, exactly as an independent opaque plane run through this same kernel over the filter canvas, while Patchy keeps alpha; PS's RGB there matched neither a nearest-visible extension nor premultiplied filtering (up to 18 and 110 levels off), so it is unresolved.
  - Motion Blur: one fixed premultiplied line at the entered angle, distance d = d+1 even taps; Q16 direction and bilinear weights, integer sums. Three kernels, one contract (`render_motion_blur`): axis angles (steps quantize to whole pixels) use an exact running sum at every distance; other angles use the tap kernel through 64 px (merged sparse kernel for interior pixels, per-tap clamping at the edges, byte-identical to the original single-threaded loop); above 64 px a sheared running sum (quarter-pixel sheared rows with a minor-axis blend, prefix integrals over the Q8 window [first-1/2, last+1/2], two-row blend) runs O(1) per pixel. It is not byte-identical: within 4 levels of the taps on noise at 65 px, except near 45/135 degrees, where the taps' own bilinear smear is softer (max 23 on per-pixel noise); `motion_blur_running_sum_tracks_tap_kernel` bounds both. `motion_blur_tap_and_axis_kernels_match_reference_bytes` pins the byte identity against a copy of the original loop. Kernels fan out over row blocks (`run_filter_blocks`); only the calling thread reports progress or throws FilterCancelled.
  - Plastic Wrap: deterministic integer height-field render; bounds/alpha byte-exact; Patchy-original pixels, no byte-identity claim.
  - Blur, Blur More, Sharpen, Sharpen More (`render_classic_kernel`): byte-exact 3x3 kernels, pinned by `photoshop-smart-filter-classic.psd` (noise with mixed alpha, a stack, content crossing the canvas edge). Blur: cross 1-4-1 / 8; Blur More: 1-2-1 / 2-2-2 / 1-2-1 / 14; Sharpen: centre 8, cross -1, / 4; Sharpen More: centre 12, all eight neighbours -1, / 4. Edge-repeat at the FEid canvas edge, quotients round half up, alpha takes the same kernel. The blurs run premultiplied (`p = round(c*a/255)`, back `round(P*255/A)`); the sharpens run on straight RGB with transparent pixels borrowing the nearest visible colour (Median's extension). One transparent pixel of padding inside the canvas replaces full-canvas embedding; blurs grow by one pixel. Known tolerance: the sharpens' extension (`extend_transparent_colors_columns_first`) breaks equal-distance ties by the nearest visible pixel in the same column (below first), then the nearer column, then the right one. That rule leaves 18 of about 6700 channel samples on a noise-with-holes probe and 1 of 522 fixture pixels off (diagonal ties); the fixture test allows 1 in 200 for the sharpens only.
  - Sharpen Edges (`render_sharpen_edges_kernel`), a fitted model pinned by `photoshop-smart-filter-sharpen-edges.psd`: per channel (alpha included) out = round((S*(255-w) + Sh*w)/255), where Sh is the byte-rounded Sharpen above and w = round(clamp(floor(|Sobel(S)|) - 64, 0, 191)*255/191) from that channel's 3x3 Sobel magnitude. Within one level of PS on 99.65% of probe samples; same extension and padding as the sharpens. The 64 and 191 are fixed constants, never user-set, ranked or image-derived ([patent-research-smart-sharpen.md](patent-research-smart-sharpen.md)).
  - Average (`render_canvas_average_effect`): every visible pixel takes the mean straight RGB over the whole FEid canvas, rounded half up; alpha and bounds unchanged. PS counts each transparent pixel by its stored hidden color (white outside the placed content, the embedded layer's color inside); Patchy counts all of them as white, so it matches PS where hidden colors are white (probes `avg1..3`, an opaque square on transparency) and drifts elsewhere. PS's destructive Average averages stored hidden colors too; Patchy's destructive Average uses the alpha-weighted mean of visible pixels instead ([filters.md](filters.md)).
  - Invert (`render_invert_effect`): `255 - c` on straight RGB, alpha and bounds unchanged; byte-exact (`photoshop-smart-filter-invert.psd`, including Invert then Blur and a layer past the canvas edge).
  - Radial Blur Zoom (`radial_zoom_kernel`): Patchy's own ray average about the content center, like Spin; samples 8/16/32 by quality at scale factors spread evenly over `1 +/- amount / 400`, Photoshop's streak extent read off dot probes (a dot at distance d streaks over d/(1+a/400)..d/(1-a/400)). Not byte-exact: on `photoshop-smart-filter-zoom.psd` (smooth gradients, Zoom 10 Draft, 25 Best, 60 Good) the mean opaque RGB difference is 0.26..1.8 levels and alpha differs by up to 51 at streak ends; per-pixel noise reaches about 6. The test pins mean <= 3 and alpha <= 64.
  - Mosaic, Emboss, Box Blur, Radial Blur (Spin), Add Noise: pinned byte-equal to the corresponding destructive filters (Box Blur above radius 12 via an exact integer sliding window; Radial Blur about the content center; Add Noise deterministic position-hashed from the seed, Patchy's own noise, not PS's).
- Distort and Stylize filters are table-described: [smart-filters-distort-stylize.md](smart-filters-distort-stylize.md). Oil Paint (stringID `oilPaint`) stays unmodeled and preview-locked: no claim-level legal record covers its brush-stroke stylization, and its GPU algorithm cannot be reproduced from probes.
- Blur Gallery: native Tilt-Shift = stringID `blurbTransform`, filter id 712, entry `Blur Gallery...`; gallery descriptors can hold multiple widgets and are not calibrated. Patchy's Lens Blur, Iris Blur, and Tilt-Shift stay destructive/gallery-only; imported gallery stacks stay byte-preserved and preview-locked; a direct or mixed gallery recipe rasterizes rather than authoring or partially executing `blurbTransform`; no private PSD block is invented.
- Blur Gallery stays locked because rendering it, imported or authored, would use the methods the Blur Gallery patents describe for most descriptors: Field Blur pins, combined widgets, bokeh boost and Path Blur (claims in [patent-research-blur-gallery.md](patent-research-blur-gallery.md)). The only fixture `blurbTransform` is the committed Tilt-Shift (widget type 3, Distortion -27.25). Proposed there, NOT approved: render only a lone enabled Tilt-Shift (Distortion 0), Iris, Spin or one-pin Field widget with Light Bokeh 0 through Patchy's recorded single-pattern designs, within a documented tolerance of Photoshop (never byte-exact).
- Stack semantics: each nondefault blend/opacity result source-over composites onto the previous result; Normal 100% replaces. The shared document-space mask applies once to the completed stack. Editing rebuilds the unfiltered placed/warped raster before running the stack; placement, warp, Edit Contents, linked refresh, Relink, and Replace Contents regenerate the FEid cache. The first supported filter seeds the mask from the exact selection alpha; no selection writes an all-white mask. Editable native masks cap at 64 megapixels; larger imported records stay preview-locked.
- Untouched SoLd and FEid/FXid payloads stay byte-exact. Rekeying duplicates changes only the Pascal `placed` id and rebuilds the envelope; the cloned FEid record must sit directly AFTER its source, and the cloned layer needs a fresh native `lyid` (PS rejects wrong cache order and merges duplicate lyids); Patchy allocates the next unused native id independently of runtime `LayerId`. Unknown versions, malformed bounds/lengths, trailing row data, unsupported depth/compression, missing associations, and duplicate `placed` matches fail closed; any opaque FEid/FXid block disables association and mutation store-wide. If ANY `filterFXList` entry is unsupported the whole stack stays preview-locked; never execute a known prefix over PS's baked preview. No private fallback block.
- **Approximate renders.** A modeled filter whose pixels Patchy cannot reproduce (Plastic Wrap, Add Noise, the randomized filters in [smart-filters-pixelate-render.md](smart-filters-pixelate-render.md), the distortions not yet byte-exact in [smart-filters-distort-stylize.md](smart-filters-distort-stylize.md)) still unlocks its stack, because opening NEVER re-renders: an untouched layer shows Photoshop's baked pixels, and Patchy renders the stack only after an edit to that layer (its stack, mask, placement, contents or the document geometry). Keep any new open-time refresh away from supported stacks; `ui_smart_filter_table_approximate_stacks_keep_photoshop_pixels_on_open` and its distort-stylize sibling pin it.
- Fixture inventory: [smart-objects.md](smart-objects.md). PS ignores written `filterMaskLinked=true`; Patchy preserves the flag but keeps that stack preview-locked.


The self-authored `cmyk-render/smart-filtered-{8,16}.psd` fixtures add Gaussian Blur
through Photoshop COM to `smart-gradient.psd`; `smart-gradient-16.psd` is its
unfiltered 16-bit conversion. Edited parent previews widen to their parent depth.
Acceptance covers unchanged, regenerated and moved caches plus embedded-content
edits in PSD and PSB, with error-enabled Photoshop opens.

## Preview-locked filters: what the user should see (recommendation)

Not implemented. A stack that keeps Photoshop's preview says only that it holds unsupported
data. Recommended: name the filter and the reason in the lock tooltip and status text, e.g.
"Patchy cannot run Photoshop's Adaptive Wide Angle filter. The layer shows the result Photoshop
saved. To edit it, hide or delete that filter, or rasterize the layer." Reasons by filter:
Adaptive Wide Angle (Adobe US 8525871 family, active), Neural Filters (Adobe's models), Camera
Raw, Liquify and Lighting Effects (not modeled), Lens Correction with a profile (Adobe lens
data), gallery effects on a built-in texture (Adobe assets). Vanishing Point never occurs:
Photoshop refuses it on a Smart Object (October 2026 probe).
