# Built-in Looks

The read-only Looks Patchy ships in the Filter Gallery's Saved Looks combo. The user Look library, recipe format and gallery contracts they build on are in [filters.md](filters.md) ("Saved Looks", "Recipes").

Patchy ships 20 read-only Looks, compiled in (no resource files): `src/filters/builtin_filter_looks.{hpp,cpp}`, Qt-free, each an id, a `PATCHY_TRANSLATE_NOOP("QObject", ...)` name and one-line description, and a recipe of catalog filters only.

- **Ids** are `patchy.looks.<suffix>`, persisted, append-only: never renamed, reused or removed once shipped. They are never canonical UUIDs, so no user record can shadow, rename or delete one (a `<built-in id>.json` file fails the UUID check).
- **Combo layout** (`filterGallerySavedLooksCombo`): Custom, a disabled bold "Built-in Looks" heading, the built-in Looks in table order (tooltip = description), then, when the user has any, a "My Looks" heading and the user Looks. Rename and Delete stay disabled for a built-in Look; Save Look always creates a new user Look.
- **Size scaling.** Recipes are authored for a 4000-pixel long edge (`kBuiltinLookReferenceLongEdge`, about 12 to 16 MP). Loading one runs `builtin_look_recipe_for_size`: `FilterRegistry::scale` by layer long edge / 4000, so blur, median, edge and halftone sizes keep their proportion on any photo. Grain and noise are per pixel and do not scale.
- **Stored complete.** Each invocation is normalized at startup, so the gallery shows the values the Look renders with. No Look uses Clouds or another captured-color filter.
- **Building blocks** worth reusing: a warm tint is Vintage Sepia at Overlay; a cool tint is Invert, Sepia at Overlay, Invert; a pencil sketch is Grayscale then Gaussian Blur at Divide; Glowing Edges at Subtract darkens outlines.
- **Cost.** Every Look previews on the bounded proxy, so edge-based Looks (Comic, Watercolor, the sketches) preview slightly heavier on large photos than they apply: their pixel sizes hit the 1-pixel minimum on the proxy. Full-resolution Apply on a 16.7 MP photo (October 2026 dev box): tonal grades 1 to 4 s; Crisp Detail, Dreamy Glow, the sketches and Halftone Print 4 to 6 s; Watercolor, Comic, Oil Paint and Miniature 13 to 18 s. Surface Blur was left out: 30 s or more at that size.
- **Tests:** `builtin_looks_*` (core: ids, normalization, scaling, one 8-bit render pin per Look, 16-bit agreement). Each pin is an exact digest plus a block-mean signature (within 2 levels), both checked on every platform: the filter kernels are bit-identical across toolchains ([platform.md](platform.md#floating-point-determinism)). `ui_filter_gallery_builtin_looks_*` cover load, preview, Apply and Undo at 8 and 16 bits, and the read-only library. `ui_filter_gallery_builtin_look_shots_if_available` captures the gallery with several Looks on `local-test-fixtures/looks/sample-photo.png` (any photo; skipped without it) for visual review. A filter change that alters a Look's pin is deliberate only when the Look still looks right; re-check it on a photo before re-pinning.
