# Platforms, privacy, and interface

Split from [features.md](features.md): supported platforms, privacy and file metadata, panels, Search Commands, screen modes, customization, menus, languages and themes.

- Cross-platform: Windows (x64, and native ARM64 without PDF import) leads, with native macOS (Apple Silicon), Linux (x86_64 Flatpak and AppImage; ARM64 Flatpak for the Raspberry Pi 5 and other ARM64 Linux) and a browser build; see the [platform support table](../README.md#platform-support)
- The browser build keeps the commands it cannot run (printing, scanner import, Open Folder, Files as Layers, Place Linked, folder and image-sequence export, G'MIC and GEGL filters, OpenAI Image Tools, float windows, AI control setup) in its menus: choosing one says it needs the desktop version and offers the download page
- Native C++ and Qt with CPU rendering. Large documents, high bit depths and Object Selection need more memory and time
- No telemetry or tracking, and no image uploads unless you use Plugins > Companions > OpenAI Image Tools via API Key, which sends your prompt and the images you choose (reference images, the area around your selection for Edit and Remove, the whole image for Expand, the starting image for Animate, or the image you describe) to OpenAI when you click Create, Edit, Remove, Expand, Animate or Describe Image. Optional update checks contact GitHub; one-click updates on Windows and the Linux AppImage and Object Selection's optional High Quality model download files when requested. Settings live in a plain local file; the installer leaves your file associations unchanged
- Help > About Patchy checks for a newer version; when it finds one, its Update button opens the update prompt (one-click update, the download, or the Flatpak update command)
- File > File Info shows and edits a document's metadata (EXIF, XMP, IPTC, thumbnails, AI generation data), sets the IPTC Data Mining value (for example "Prohibited for AI/ML training", also a Preferences default for new saves), flags information you may not want to share and strips it. PSD and JPEG saves record Patchy, the save dates, color mode and document IDs as Photoshop does, with a fresh thumbnail
- **Panels**: group panels into tabs (drag, reorder) and collapse them; Window > Show Panel Titles hides the title rows of open panels to give them more room (tab groups keep their tabs, collapsed panels keep their row)
- **Color panel**: hue cube with hex and RGB boxes (right-click sets background, also in the Foreground Color window) or RGB/HSB/CMYK sliders (gear)
- **Layers panel**
  - Previews blend modes while browsing (Shift+Plus/Minus steps them or a painting tool's Mode, Shift+Alt+letter sets one), with four thumbnail sizes aligned by nesting
  - Digits (00: 0%) set layer opacity off painting tools and "/" locks transparency; drag along eyes to toggle layers, or right-click one for more
  - Alt/Option-click New Layer for its dialog (fill the new layer with a color, Edit > Fill's list, or the mode's neutral color), Ctrl/Cmd-click to add below; Alt-click Add Layer Mask for a hiding mask, Ctrl/Cmd-click for a vector mask
  - Layer > Color labels a layer with any of Photoshop's eleven colors (Seafoam, Indigo, Magenta and Fuchsia included), kept in PSDs
  - Layer > Arrange > Link Layers links the selected layers so the Move tool and Free Transform take them together (a link badge marks them; Select Linked Layers selects a group), kept in PSDs
  - Row, thumbnail and badge menus hold layer, mask, style, Smart Object and Combine Shapes commands; a badge flags custom blending
  - Ctrl/Cmd-click thumbnails or channels to select (Shift adds, Alt subtracts, both intersect); Delete removes a targeted mask (offering to apply it)
  - Layer and vector mask commands (add, delete, apply, disable, invert, link, rasterize) act on every selected layer at once, one undo step
  - Blend mode, Opacity and Fill stay on one line in a narrow panel: the blend mode box narrows first, and a shortened mode name reads whole in its tooltip and in the open list. When space runs out, Opacity and Fill drop their labels and get them back when the panel is wider; their tooltips name them, and dragging a field still scrubs its value
- **Properties panel**: width, height and position of the selected layers (pixel, text, smart object, shape, folders) in the ruler unit; type a value with a unit ("5 cm", "2 in"), right-click a field to change the unit, and the link button keeps proportions. Text stays editable and smart objects stay smart
- Help > Search Commands (Ctrl+F, or the magnifier after Help): find and run any command, tool or key by name, menu or description, switch to an open document or open a recent file or folder by its name; each result shows an icon for its kind. F1 opens the [feature list](features.md)
- Screen modes (F, View menu, toolbox): full screen, with or without menus and panels; Tab hides the panels. F6, F7, F8 toggle Color, Layers, Info. Home, End, Page Up and Page Down scroll the view. Rotate View (R) turns the canvas on screen like a sheet of paper, to any angle (Shift snaps to 15 degrees, Esc turns it upright); painting, selections, transforms and text all work turned, and the image itself never changes
- **Customize Tool Palette**: hide tools, color, Quick Mask and screen mode buttons; two columns, wheel scroll (with or without its scroll arrows and > arrow), icon size, no tool groups; groups open on hold, click or hover. A tool group's letter selects the tool the group last used and Shift+letter walks the group; with Preferences > Use Shift for tool switch off, the plain letter walks it too
- **Customize Layers Panel** (its gear menu): hide, reorder, presets, size, optional move, merge and a rasterize menu, plus compact rows without the blend mode and opacity line, row tooltips on or off, the Fill field shown or hidden (hidden, the blend mode and Opacity fit one line in the narrowest panel), color labels as a strip or a tint over the whole row, and the thumbnail size and display
- Preferences > Hotkeys: change any shortcut, search by name or key, show only menu commands, commands with shortcuts (the search then looks only at the keys, so "u" finds Ctrl+U and not Undo), tools or other commands, start from Patchy's keys or a built-in Photoshop-style, GIMP-style or Krita-style set (built-in sets never change: your edits go to a Custom set you can rename), keep named sets of your own, and export your shortcuts to a `.patchykeys` file to keep, share or import as a new set on another machine; Ctrl+Alt+Shift+K (Cmd+Option+Shift+K) opens this page
- GIMP-style and Krita-style shortcut sets also move the canvas tool modifiers those programs put on Ctrl: Ctrl zooms out with the Zoom tool, picks colors with the painting tools and sets the Clone and Healing source (GIMP-style also: Ctrl+wheel zooms, Ctrl swaps Dodge and Burn or Blur and Sharpen, Ctrl subtracts from a selection); Patchy default and Photoshop-style keep Alt for all of these
- Layers panel filter: beside the name field, a filter menu lists only the layers of chosen types (pixel, text, shape, fill or adjustment, smart object, folder), properties (mask, layer style, hidden, locked, linked, Smart Filters), row colors or the selected layers; choices combine with each other and the name text, and one click clears them
- Layer menu: Bring to Front/Send to Back (Shift+Ctrl+]/[), Arrange > Reverse (reverse the selected layers, for backward or bounce animations), Hide & Lock > Lock Layers... (Ctrl+/), Hide/Show Layers (Ctrl+,) and Show All (Ctrl+Alt+,), Export > Quick Export as PNG (Ctrl+Shift+'), Export As (Ctrl+Shift+Alt+') and Duplicate Layer to Document..., Rasterize (the Layers panel menu's Rasterize entries), Layer Style (each effect page, copy, paste and delete, Show Layer Styles), Fill and Adjustment Layer settings; Preferences... (Ctrl+K) at the end of the Edit menu (the app menu on macOS)
- Localized in twelve languages: English, German, Spanish, French, Italian, Brazilian Portuguese, Russian, Polish, Japanese, Korean, Chinese (Simplified and Traditional), following the system or Preferences, which also set the interface scale and a separate text size (80% to 125%)
- UI themes: Dark, Light, eight bundled themes (Darkest, Medium Gray, Solarized Dark, Nord, Dracula, Gruvbox Dark, High Contrast, Dink Smallwood), or your own: a `.patchytheme` color file or a theme package (folder or .zip) adding SVG, PNG, BMP icons, a tiled backdrop, event sounds and effects (fireworks, confetti, sprites), and sandboxed scripts for a theme menu, cursors and a splash. Preferences > Colors and Themes previews each theme, its startup sound, version, author and description, warns if it needs a newer Patchy, keeps script trust per theme, imports and exports. Start from [themes/example-package](../themes/example-package/theme.json)
