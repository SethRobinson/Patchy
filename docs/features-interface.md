# Platforms, privacy, and interface

Split from [features.md](features.md): supported platforms, privacy and file metadata, panels, Search Commands, screen modes, customization, menus, languages and themes.

- Cross-platform: Windows (x64, and native ARM64 without PDF import) leads, with native macOS (Apple Silicon), Linux (x86_64 Flatpak and AppImage; ARM64 Flatpak for the Raspberry Pi 5 and other ARM64 Linux) and a browser build; see the [platform support table](../README.md#platform-support)
- Native C++ and Qt with CPU rendering. Large documents, high bit depths and Object Selection need more memory and time
- No telemetry, tracking or image uploads. Optional update checks contact GitHub; one-click updates on Windows and the Linux AppImage and Object Selection's optional High Quality model download files when requested. Settings live in a plain local file; the installer leaves your file associations unchanged
- File > File Info shows and edits a document's metadata (EXIF, XMP, IPTC, thumbnails, AI generation data), flags information you may not want to share and strips it. PSD and JPEG saves record Patchy, the save dates, color mode and document IDs as Photoshop does, with a fresh thumbnail
- Group panels into tabs (drag, reorder), collapse them. Color panel: hue cube with hex and RGB boxes (right-click sets background, also in the Foreground Color window) or RGB/HSB/CMYK sliders (gear); the Layers panel previews blend modes while browsing (Shift+Plus/Minus steps them or a painting tool's Mode, Shift+Alt+letter sets one) and has four thumbnail sizes aligned by nesting. Digits (00: 0%) set layer opacity off painting tools; "/" locks transparency. Alt/Option-click New Layer for its dialog (with neutral fills), Ctrl/Cmd-click to add below; Alt-click Add Layer Mask for a hiding mask, Ctrl/Cmd-click for a vector mask. Drag along eyes to toggle layers; right-click one for more. Layer > Color labels a layer with any of Photoshop's eleven colors (Seafoam, Indigo, Magenta and Fuchsia included), kept in PSDs. Row, thumbnail and badge menus hold layer, mask, style, Smart Object and Combine Shapes commands; a badge flags custom blending. Ctrl/Cmd-click thumbnails or channels to select (Shift adds, Alt subtracts, both intersect). Delete removes a targeted mask (offering to apply it)
- Help > Search Commands (Ctrl+F, or the magnifier after Help): find and run any command, tool or key by name, menu or description, switch to an open document or open a recent file or folder by its name; each result shows an icon for its kind. F1 opens the [feature list](features.md)
- Screen modes (F, View menu, toolbox): full screen, with or without menus and panels; Tab hides the panels. F6, F7, F8 toggle Color, Layers, Info. Home, End, Page Up and Page Down scroll the view. Rotate View (R) turns the canvas on screen like a sheet of paper, to any angle (Shift snaps to 15 degrees, Esc turns it upright); painting, selections, transforms and text all work turned, and the image itself never changes
- Customize Tool Palette: hide tools, color, Quick Mask and screen mode buttons; Layers Panel tab (Customize Layers Panel... in its gear menu): hide, reorder, presets, size, optional move, merge and a rasterize menu; two columns, wheel scroll, icon size, no tool groups; groups open on hold, click or hover. Shift+letter walks a tool group; with Preferences > Use Shift for tool switch off, the plain letter does too
- Preferences > Hotkeys: change any shortcut, search by name or key, start from Patchy's keys or a built-in Photoshop-style, GIMP-style or Krita-style set (built-in sets never change: your edits go to a Custom set you can rename), keep named sets of your own, and export your shortcuts to a `.patchykeys` file to keep, share or import as a new set on another machine; Ctrl+Alt+Shift+K (Cmd+Option+Shift+K) opens this page
- Layer menu: Bring to Front/Send to Back (Shift+Ctrl+]/[), Hide & Lock > Lock Layers... (Ctrl+/), Hide/Show Layers (Ctrl+,) and Show All (Ctrl+Alt+,), Export > Quick Export as PNG (Ctrl+Shift+'), Export As (Ctrl+Shift+Alt+') and Duplicate Layer to Document..., Layer Style (each effect page, copy, paste and delete, Show Layer Styles), Fill and Adjustment Layer settings; Preferences... (Ctrl+K) at the end of the Edit menu (the app menu on macOS)
- Localized in twelve languages: English, German, Spanish, French, Italian, Brazilian Portuguese, Russian, Polish, Japanese, Korean, Chinese (Simplified and Traditional), following the system or Preferences, which also set the interface scale and a separate text size (80% to 125%)
- UI themes: Dark, Light, eight bundled themes (Darkest, Medium Gray, Solarized Dark, Nord, Dracula, Gruvbox Dark, High Contrast, Dink Smallwood), or your own: a `.patchytheme` color file or a theme package (folder or .zip) adding SVG, PNG, BMP icons, a tiled backdrop, event sounds and effects (fireworks, confetti, sprites), and sandboxed scripts for a theme menu, cursors and a splash. Preferences > Colors and Themes previews each theme, its startup sound, version, author and description, warns if it needs a newer Patchy, keeps script trust per theme, imports and exports. Start from [themes/example-package](../themes/example-package/theme.json)
