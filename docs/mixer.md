# Mixer Brush and Stroke Smoothing

Topic reference for the Mixer Brush's limited continuous-pickup engine, its calibration record, and the shared stroke Smoothing stabilizer. The stamping engine, tips, and dynamics live in [brushes.md](brushes.md); the binding patent rules live in [legal-constraints.md](legal-constraints.md) with the research record in [patent-research.md](patent-research.md).

## Mixer Brush

Mixer Brush is a separate tool in the Detail flyout. Options bar: Useful Combinations dropdown (Custom + the 12 Photoshop presets; selection DERIVED from current Wet/Load/Mix, never persisted; dry rows ignore Mix; values await one in-Photoshop verification, table in main_window_actions_options_bar.cpp), Size, Softness, Wet, Load, Mix, Flow, Sample All Layers, Tip. Wet = pickup chase rate and picked-color share; Load = Wet-0 dry-out distance; Mix = picked/foreground deposit ratio (disabled at Wet 0); Flow meters dabs through the ordinary stroke compositor.

The color model is LIMITED continuous pickup (claim re-review 2026-08-14). Each dab averages a 9x9 disc of the STROKE-START SNAPSHOT of the active layer (`CanvasWidget::sample_mixer_pickup` over `brush_stroke_original_pixel`, alpha-weighted) into ONE running premultiplied-RGBA average (`MixerBrushState`) at rate `1 - exp(-dab_distance/L)`. The store is canvas-only: seeded from the first dab, the foreground NEVER enters it; the deposit is a transient linear lerp between foreground and store, never written back. Snapshot reads are deliberate: without Photoshop's paint-amount reservoir (legally excluded) a live read re-ingests the stroke's own deposit and a smear never fades; the cost is that a stroke cannot smear its own fresh paint. Transparency and off-layer thin the deposit. **Sample All Layers** (key `tools/mixerSampleAllLayers`, default off = Photoshop parity, separate from the retouch flag) swaps in one merged-document snapshot at stroke start (`render_document_image_with_processing`); still one canvas-only source per stroke. `ui_mixer_sample_all_layers_switches_stroke_start_sample` pins both states.

Calibration (PS 2026 COM captures in `local-test-fixtures/mixer-calibration/`; AM `Strk` with `Usng wetBrushTool`, reservoir reset by tool-switch since no scripted clean exists and auto-clean skips scripted strokes): `L = D*(0.15 + 2.35*wet)`; deposit ratio `r = interp(wet)*interp(mix)/0.47` clamped to [0,1], anchors wet(m50) 0.10=0.34, 0.25=0.41, 0.50=0.47, 0.75=0.54, 1.00=0.60; mix(w50) 0=0, 0.25=0.35, 0.50=0.47, 0.75=0.69, 1.00=0.97. Wet 0 is a hard dry brush (r=0) with the only dry-out: alpha ramps linearly to zero over `D*(6.6 + 24*load)`, none at Load 99.5%+; wet strokes never dry (no fade in 530 px at Load 1). Constants: `kMixer*` in pixel_tools.cpp.

A Mixer stroke may use the Round tip or any static `.abr` tip and its spacing. Ordinary Brush dynamics do not apply; Wet/Load/Mix/Flow are tool settings, not `.abr` dynamics.

`ui_mixer_brush_uses_compact_controls_and_round_trips_raster_pixels` pins the options bar and exact layered PSD reopen; `ui_mixer_useful_combination_presets_set_wet_load_mix` pins the combination dropdown; `mixer_brush_pickup_average_follows_canvas_and_dries_only_at_wet_zero` pins the core model; `mixer_dab_segment` in `tool_write_paths_digest_baseline` pins its bytes; `ui_mixer_calibration_contact_sheet` renders the Patchy half of the Photoshop comparison matrix. Palette mode uses the common brush writer and snaps each result to the document palette; Wet Edges is omitted there because a tonal edge cannot survive the hard palette constraint.

## Stroke Smoothing

Brush, Mixer Brush, and Eraser (pen eraser end included) share a Photoshop-style Smoothing percent plus gear toggles: Pulled String Mode, Stroke Catch-up, Catch-up on Stroke End, Adjust for Zoom. Core `src/core/stroke_stabilizer.*` is a pure taut-leash stabilizer between the Shift axis constraint and the midpoint smoother; 0% never consults it, so strokes stay byte-identical. `CanvasWidget::stroke_stabilizer_leash_radius` maps percent to document px (Adjust for Zoom on) or screen px / zoom (off). Stationary catch-up is tick-driven: a 16 ms timer feeds the core a fixed dt (no clock reads in core, deterministic) and stops wherever the airbrush timer stops. The leash overlay draws with the `brush_leash` theme role. Keys: `tools/brushSmoothing`, `tools/brushSmoothingPulledString`, `tools/brushSmoothingCatchUp`, `tools/brushSmoothingCatchUpEnd`, `tools/brushSmoothingZoomAdjust`. Patent boundary (2026-08-14 entry in [patent-research.md](patent-research.md)): geometric leash only; no model mass/drag or speed-adaptive strength (Adobe US 9411796), no incremental Bezier fitting. Tests: `stroke_stabilizer_pass_through_and_leash_geometry`, `ui_brush_smoothing_options_bar_round_trips_settings`, `ui_brush_smoothing_pulled_string_short_drag_paints_only_press_dab`, `ui_brush_smoothing_catch_up_on_end_completes_stroke`.
