# Layers panel filter

Part of [layer-panel.md](layer-panel.md), which owns the absent-row rules and drag blocking the filter relies on.

GitHub issue 671; Patchy's own design ([legal-constraints.md](legal-constraints.md#layers-panel-filter): never another editor's filter row, modes or order). `layerFilterButton`, just left of the name field in the lock row (it wraps with the field), pops up `layerFilterMenu`: Layer Type (Pixel, Text, Shape, Adjustment or Fill, Smart Object, Folder), Properties (Has a Mask, Has a Layer Style, Hidden, Locked), the Row Color submenu (`layerFilterColorMenu`, the Layer > Color names and swatches; its entry counts the ticked colors), Selected Only, and Clear Filter. A mouse click on a checkable entry toggles it and keeps the menu open (`LayerFilterMenuKeepOpen`). Within a group a layer matches any ticked entry; every group with a tick, Selected Only and the name text must all match (`layer_matches_list_filter`, `layer_name_matches_filter`). Smart Objects are found by `layer_is_smart_object`, fill layers count as Adjustment or Fill, vector shapes as Shape, the Background as Locked; Hidden and Locked read the layer's own state, not its folder's. As with the name filter, a folder is listed when it or a descendant matches, and a matching folder brings no children.

- **State**: `DocumentSession::layer_filter` (`LayerListFilter`), per document, never in the file or settings; the name text stays one field for every document. While a criterion is ticked the button carries `layerFilterActive` (the checked-lock roles in QSS) and `layerFilterClearButton` shows beside it; it and Clear Filter clear the criteria and the name text (`clear_layer_list_filter`). Toggling keeps a listed multi-selection (`refresh_layer_list_for_filter`), never moving the active layer.
- **Selected Only** lists `selected_ids` plus the active layer. Ticking it snapshots the selection. Selections made outside the panel replace the snapshot: `reveal_layer_in_layer_list` and `select_layers_in_layer_list` without `clicked_in_panel` (canvas picks, layer commands), rebuilding with `layer_filter_pending_active_` so the incoming layer is the listed active one. Clicks in the panel leave it, so the rows stay to pick among.
- **Reveal**: when a reveal or select target fails the name text or a criterion, both functions clear the whole filter (`clear_layer_list_filter_silently`) and rebuild; `insert_duplicated_layer_rows` declines while any filter is on.
- Tests: `ui_layer_filter_menu_*`, `ui_layer_filter_button_active_state_in_both_schemes` (tests/ui/layer_filter_menu_tests.cpp; artifacts `issue_671_*`).
