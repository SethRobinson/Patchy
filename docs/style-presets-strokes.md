# Stroke presets and the Stroke Presets manager

Split from [style-presets.md](style-presets.md): Shape Appearance's saved stroke presets (one Dashes list with the built-in dash presets, what a preset holds, naming, matching, storage) and the Stroke Presets manager. The built-in dash presets and the rest of the Shape Appearance dialog are in [vector-tools-appearance.md](vector-tools-appearance.md).

## Shape Appearance stroke presets

Built-in and saved stroke presets are one list (GitHub issue 557 and its follow-up). Shape Appearance's Dashes combo (`shapeStrokeDashCombo`) lists the built-in dash presets, a separator, the user's saved stroke presets (item data `kSavedStrokePresetRow` + index) and Custom, with Save... and Delete beside it (there is no separate Preset row). A saved preset holds Align, Caps, Corners, the dash array and the dash offset (`StrokeStylePreset`, shape_appearance_dialog.hpp); width and paint stay out, so one preset suits any stroke. Save... asks for a name (`shapeStrokePresetNameDialog`, prefilled with the chosen saved preset's name); an existing name is replaced in place and a built-in's name is refused (`stroke_preset_name_is_builtin`, case-insensitive in the UI language). Delete removes the chosen saved preset. Picking a saved row applies it in one preview step; the combo shows Custom while the user edits a pattern, else the first saved preset the settings match (`matching_stroke_style_preset`; a solid stroke's offset is ignored), else the built-in or Custom. The options bar's dash combo is the same list ([options-bar.md](options-bar.md)). Storage: the app setting `shapeAppearance/strokeStylePresets` (`kStrokeStylePresetsKey`, permanent), a JSON array of `{name, alignment, cap, join, dashes, dashOffset}` using the scripting API's tokens; unreadable entries are skipped. Test: `ui_shape_appearance_dash_offset_and_stroke_presets`.

The Stroke Presets manager (`request_stroke_preset_manager`, stroke_preset_manager_dialog.cpp; `strokePresetManagerDialog`) lists the built-ins first, then the saved presets, each with a line sample (`stroke_style_preset_sample`, theme text color; it shows caps, corners, dashes and offset, not alignment), its dash and gap values in a second column (`stroke_style_preset_dash_values`: pairs as "dash gap" in stroke widths, separated by " | ", then "offset N" when not 0; empty for solid) and Built-in in a third. A built-in (`builtin_stroke_style_preset`) shows its settings as text, Unchanged for what it does not set; its Name, Move Up/Down and Delete are disabled and a note says so, but Use Preset and Duplicate work. Duplicate copies any row into a new saved preset at the end of the list (`stroke_preset_copy_name`: "<name> copy", then "copy 2" and up, free among saved and built-in names), selected with its name ready to edit. For saved presets the Name field renames (a saved or built-in name is refused, since Save... replaces by name), Align, Caps and Corners are combos, Dashes is a pattern field in the Dash pattern format (empty makes it solid and zeroes the offset; text that is not a pattern reverts) and Dash offset a spin box (off while solid); Move Up and Move Down reorder below the built-ins, Delete asks first; each edit writes the setting at once, and both Dashes lists read it (the options bar rebuilds when the manager closes, Shape Appearance when it opens). Use Preset (or a double-click) returns a `StrokePresetChoice` (a built-in or a saved preset), which MainWindow applies like the options bar's dash combo. Tests: `ui_stroke_preset_manager_edits_round_trip_through_the_setting`, `ui_stroke_preset_manager_duplicates_and_edits`.
