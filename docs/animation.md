# Animation import and export

- GIF: Patchy-owned encoder for single frames and animations; reading stays with Qt's qgif, so the Windows package must ship `imageformats/qgif.dll`. Opening a 2+ frame GIF imports every frame as a visible layer, frame 1 on TOP (reversed from the sequence/sprite-sheet convention so open-then-save round-trips), each delay stamped as a trailing seconds token ("Frame 3 0.4s") that the animated save parses back (`gif::format_delay_seconds_token` / `parse_layer_name_delay_cs`; the pattern library stays first-frame-only). Save As / Export .gif on a 2+ layer document raises `prompt_gif_save_options` (animation from visible layers vs single flattened image, default frame delay; keys `saveOptions/gifSaveMode`, `saveOptions/gifFrameDelayCs`; an explicit animation choice skips the flatten warning but keeps save-a-copy semantics); File > Export > Layers as Animated GIF is the always-animation form and stays visible on wasm. Animated writes (`write_animated_gif_file`): visible top-level layers top to bottom through `render_layer_isolated`, per-frame quantization (`indexed_rgba8_quantized`/`indexed_rgba8_with_palette`), NETSCAPE2.0 loop forever, disposal restore-to-background, global color table = frame 1 with local tables for later frames, no dithering. LZW width growth uses the pre-increment check; `gif_encoder_bytes_are_stable` pins the single-frame bytes, which the animation path never touches. The layers panel's film button previews the animation ([layer-panel.md](layer-panel.md)).

- Animated PNG (GitHub issue 119): `src/ui/apng_reader` splits the acTL / fcTL / fdAT stream into one standalone PNG per frame (the file's IHDR at the frame's size, its PLTE / tRNS / color chunks, fdAT rewritten as IDAT), decodes each through Qt and composites them with the frame's dispose (none / background / previous; a first-frame "previous" counts as background) and blend (source / over) ops into full-canvas frames. Opening a 2+ frame APNG (`.png` or `.apng`) imports them like GIF frames: frame 1 on top, all visible, millisecond seconds tokens. A default image with no fcTL before its IDAT is a still-viewer fallback and is skipped; out-of-order sequence numbers, a frame outside the canvas or an undecodable frame reject the animation and the open keeps the default image with a notice; the file's acTL play count goes into document metadata `apng.loop_count`. Conformance corpus: imazen/codec-corpus `apng-conformance` (CC0), copied to `local-test-fixtures/apng-conformance` for sweeps; the tests build their own files.
- Animated PNG export (GitHub issue 366): File > Export > Layers as Animated PNG (`file.export_animated_png`, `MainWindow::export_animated_png`) and `doc.exportAnimatedPng` write the visible top-level layers through the shared frame path (`write_animated_png_file`, `AnimatedFormat::Png`; trim union, transforms, name timing, the default delay in `saveOptions/animationFrameDelayMs`). Save As .png never animates in the UI (`ImageSaveOptions::apng_animate` is set only by the export action, File > Export for Web's Animation group, `doc.exportAnimatedPng` and the `.png` `animate` key of `saveAs`/`exportAs`/`encodeForWeb`). The options dialog (`apngSaveOptionsDialog`) has the default delay, Forever / Play count (acTL num_plays, 0 forever; offered from `apng.loop_count`, written back after an export) and the Export section with Metadata. Encoder `src/formats/apng_writer` (Qt-free, miniz at the default level, so deterministic): 8-bit RGBA IHDR, pHYs from the document resolution, acTL, then frame 1 as fcTL + IDAT (the default image is frame 1, so plain PNG viewers show it) and later frames as fcTL + fdAT holding only the rectangle that changed from the frame before (dispose none, blend source; an identical frame stores one unchanged pixel so the frame count stays one per layer). Rows take the minimum-sum-of-absolute-differences filter; compressed data splits into 1 MiB chunks. Delays are num/1000 up to 65.535 s, then centiseconds, then whole seconds. Metadata goes in through `inject_metadata` after IHDR. Tests: `apng_encoder_writes_frame_chunks_in_sequence` (core), `ui_apng_export_round_trips_through_the_apng_reader`, `ui_apng_export_dialog_options`, `ui_script_apng_animation_export_preserves_document_and_validates_options`.
- Animated WebP: private libwebp 1.6.0 (`formats/webp_animation_io`, `cmake/patchy_webp.cmake`) decodes composited RGBA frames with native blend/disposal handling. Frames become visible layers, first frame on top, named with millisecond seconds tokens. The decoder checks canvas allocation limits, complete frames and signed timestamp overflow. Still WebP continues through Qt. Save As / Export on a layered document offers animation or flattened output (`saveOptions/webpSaveMode`); File > Export > Layers as Animated WebP (`file.export_animated_webp`) always animates. Visible top-level layers, groups, trim union and transforms share the GIF rendering path. Encoder input is RGBA, preserving partial alpha, with per-frame name timing or the default delay, lossless/quality controls and Forever or a total play count. Identical consecutive frames may coalesce; a single resulting frame may be stored as a still. Failures leave an existing destination intact via the atomic writer.

- Animated JPEG XL: imports and exports like animated WebP through libjxl, with its own `saveOptions/jxlSaveMode` and document metadata `jxl.loop_count`; frames are 8-bit. Details in [jxl.md](jxl.md).

- Animation timing: `formats/animation_timing` parses seconds to integer milliseconds and formats up to three decimals. Preview and WebP share `saveOptions/animationFrameDelayMs` (migrated from `gifFrameDelayCs`); editing either format's default updates the other at its precision. GIF's direct centisecond parser and byte canary remain unchanged. WebP loop count 0 means forever; positive values count total plays. Imported/chosen counts live in document metadata `webp.loop_count`, not global settings or PSD/recovery serialization. New documents default to forever. Scripts use `doc.exportAnimatedWebp`; ordinary scripted WebP saves remain flat.

- Codec isolation: libwebp is statically linked on desktop and wasm, with private symbol names generated by `scripts/dev/generate-webp-symbols.py`. Two upstream function-like macros need namespace-only edits, recorded in `src/formats/libwebp/PATCHY.md`. Update the pinned sources, regenerate that header, and audit defined globals against Qt when upgrading. Tools and codec threads are disabled. No FFmpeg is used for WebP.

The WebP, JPEG XL, APNG and GIF dialogs build their timing rows with `create_animation_timing_controls` and the Export section's Transparency group with `add_transparency_choice` (image_save_options_dialog); Export for Web uses the same two helpers ([web-export.md](web-export.md)).

Export for Web plays an animated GIF, WebP, JPEG XL or PNG in its preview from the encoded file's
frames beside the source frames of `for_each_animation_export_frame`, the frame list every
animated writer uses ([web-export.md](web-export.md#animation-playback)).

## Animation preview window

The film button (`layerAnimationButton`) and Image > Animation Preview (`imageAnimationPreviewAction`, command `image.animation_preview`, unbound; GitHub issue 512; `ui_image_menu_opens_animation_preview`) toggle `AnimationPreviewWindow` (`src/ui/animation_preview_window.{hpp,cpp}`, the TilePreviewWindow pattern). It reads top to bottom (GitHub issue 198), each group a grid with its label and field on the first row, the options under the field and its buttons at the right of the last row: a Playback group ("Default frame delay", then "Ignore delays in layer names", "Play hidden layers", and the frame counter beside Play), then a "Layer names" group ("Frame delay", "Apply to all layers", Set Time and Remove Time). Both delays are one control each, the Preferences interface-scale pattern: a `DelaySecondsSpinBox` (type seconds, unit optional; - and + step 0.1 s; text it cannot use, empty, non-numeric or over the maximum, puts the last value back) with a chevron presets drop-down against it (0.05/0.1/0.2/0.5/1 s, the held value ticked). Both fields stretch (at least "9999.19 s" wide) so each drop-down ends at the right edge of the buttons below, and the two labels share a width so the fields start at the same x (`ui_animation_preview_ignores_name_delays_and_plays_hidden_layers` checks both, also with the window widened). Play cycles initially visible top-level layers from top to bottom, hiding the others; "Play hidden layers" cycles every top-level layer (toggling it mid-play restarts playback). A trailing seconds token overrides the default unless "Ignore delays in layer names" is on. Both checkboxes are preview-only: export keeps visible layers and name times. They persist in `animationPreview/ignoreNameDelays` and `animationPreview/playHiddenLayers`. The field edits shared `saveOptions/animationFrameDelayMs` (whole milliseconds) and rounds the legacy GIF default to centiseconds. Stop, closing the preview, a tab switch, or document close restores captured visibility. MainWindow calls `stop_playback_for` in `activate_document_canvas` while the outgoing document is active and early in `close_document_session`, before the save prompt. Playback mutates visibility without undo or dirtying the session. Per-frame updates use `sync_layer_row_visibility_indicators`; a full `refresh_layer_list` runs once at stop. Tests: `ui_animation_preview_plays_visible_layers_and_restores`, `ui_animation_preview_ignores_name_delays_and_plays_hidden_layers`, `ui_animation_preview_stops_on_tab_switch_and_close`; the window is in `ui_offscreen_dialog_sweep_is_themed_in_both_schemes`.

The "Layer names" group edits the name tokens: Set Time renames the selected (else active) layers, or every top-level layer with "Apply to all layers" (`animationPreview/applyToAllLayers`), to end with the group's own delay field (`animationSelectionTimeSpin`) (replacing any existing token, via `gif::strip_layer_name_delay_token` plus `format_delay_seconds_token`), Remove Time strips the token, and a name that is nothing but a token keeps it. Both go through `MainWindow::set_selected_layers_frame_time` as one undo snapshot ("Set frame time"/"Remove frame time"), and the panel stops playback (with restore) before invoking it so the snapshot never captures a preview frame's visibility; a no-op click pushes nothing and reports through `show_status_error`. Pinned by `ui_animation_preview_sets_and_removes_frame_time_names` and `ui_animation_preview_sets_and_removes_frame_time_on_all_layers`.
