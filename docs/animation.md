# Animation import and export

- GIF: Patchy-owned encoder for single frames and animations; reading stays with Qt's qgif, so the Windows package must ship `imageformats/qgif.dll`. Opening a 2+ frame GIF imports every frame as a visible layer, frame 1 on TOP (reversed from the sequence/sprite-sheet convention so open-then-save round-trips), each delay stamped as a trailing seconds token ("Frame 3 0.4s") that the animated save parses back (`gif::format_delay_seconds_token` / `parse_layer_name_delay_cs`; the pattern library stays first-frame-only). Save As / Export .gif on a 2+ layer document raises `prompt_gif_save_options` (animation from visible layers vs single flattened image, default frame delay; keys `saveOptions/gifSaveMode`, `saveOptions/gifFrameDelayCs`; an explicit animation choice skips the flatten warning but keeps save-a-copy semantics); File > Export > Layers as Animated GIF is the always-animation form and stays visible on wasm; it opens Export for Web on GIF with Animation on ([Layers as Animated exports](web-export.md#layers-as-animated-exports)). Animated writes (`write_animated_gif_file`): the frames of [Frames and layers named "all"](#frames-and-layers-named-all), top to bottom, each through `render_layers_isolated`, per-frame quantization (`indexed_rgba8_quantized`/`indexed_rgba8_with_palette`), NETSCAPE2.0 loop forever, disposal restore-to-background, global color table = frame 1 with local tables for later frames, no dithering. LZW width growth uses the pre-increment check; `gif_encoder_bytes_are_stable` pins the single-frame bytes, which the animation path never touches. The layers panel's film button previews the animation ([layer-panel.md](layer-panel.md)).

- Animated PNG (GitHub issue 119): `src/ui/apng_reader` splits the acTL / fcTL / fdAT stream into one standalone PNG per frame (the file's IHDR at the frame's size, its PLTE / tRNS / color chunks, fdAT rewritten as IDAT), decodes each through Qt and composites them with the frame's dispose (none / background / previous; a first-frame "previous" counts as background) and blend (source / over) ops into full-canvas frames. Opening a 2+ frame APNG (`.png` or `.apng`) imports them like GIF frames: frame 1 on top, all visible, millisecond seconds tokens. A default image with no fcTL before its IDAT is a still-viewer fallback and is skipped; out-of-order sequence numbers, a frame outside the canvas or an undecodable frame reject the animation and the open keeps the default image with a notice; the file's acTL play count goes into document metadata `apng.loop_count`. Conformance corpus: imazen/codec-corpus `apng-conformance` (CC0), copied to `local-test-fixtures/apng-conformance` for sweeps; the tests build their own files.
- Animated PNG export (GitHub issue 366): File > Export > Layers as Animated PNG (`file.export_animated_png`, `MainWindow::export_animated_png`, which opens Export for Web on PNG with Animation on) and `doc.exportAnimatedPng` write the visible top-level layers through the shared frame path (`write_animated_png_file`, `AnimatedFormat::Png`; trim union, transforms, name timing, the default delay in `saveOptions/animationFrameDelayMs`). Save As .png never animates in the UI (`ImageSaveOptions::apng_animate` is set only by the export action, File > Export for Web's Animation group, `doc.exportAnimatedPng` and the `.png` `animate` key of `saveAs`/`exportAs`/`encodeForWeb`). Export for Web's Animation group has the default delay and Forever / Play count (acTL num_plays, 0 forever; offered from `apng.loop_count`, written back after an export); there is no separate APNG options dialog. Encoder `src/formats/apng_writer` (Qt-free, miniz at the default level, so deterministic): 8-bit RGBA IHDR, pHYs from the document resolution, acTL, then frame 1 as fcTL + IDAT (the default image is frame 1, so plain PNG viewers show it) and later frames as fcTL + fdAT holding only the rectangle that changed from the frame before (dispose none, blend source; an identical frame stores one unchanged pixel so the frame count stays one per layer). Rows take the minimum-sum-of-absolute-differences filter; compressed data splits into 1 MiB chunks. Delays are num/1000 up to 65.535 s, then centiseconds, then whole seconds. Metadata goes in through `inject_metadata` after IHDR. Tests: `apng_encoder_writes_frame_chunks_in_sequence` (core), `ui_apng_export_round_trips_through_the_apng_reader`, `ui_web_export_layers_as_animated_open_export_for_web`, `ui_script_apng_animation_export_preserves_document_and_validates_options`.
- Animated WebP: private libwebp 1.6.0 (`formats/webp_animation_io`, `cmake/patchy_webp.cmake`) decodes composited RGBA frames with native blend/disposal handling. Frames become visible layers, first frame on top, named with millisecond seconds tokens. The decoder checks canvas allocation limits, complete frames and signed timestamp overflow. Still WebP continues through Qt. Save As / Export on a layered document offers animation or flattened output (`saveOptions/webpSaveMode`); File > Export > Layers as Animated WebP (`file.export_animated_webp`) opens Export for Web on WebP with Animation on. Visible top-level layers, groups, trim union and transforms share the GIF rendering path. Encoder input is RGBA, preserving partial alpha, with per-frame name timing or the default delay, lossless/quality controls and Forever or a total play count. Identical consecutive frames may coalesce; a single resulting frame may be stored as a still. Failures leave an existing destination intact via the atomic writer.

- Animated JPEG XL: imports and exports like animated WebP through libjxl, with its own `saveOptions/jxlSaveMode` and document metadata `jxl.loop_count`; frames are 8-bit. Details in [jxl.md](jxl.md).

- Animation timing: `formats/animation_timing` parses seconds to integer milliseconds and formats up to three decimals. Preview, WebP, JPEG XL and APNG share `saveOptions/animationFrameDelayMs` (migrated from `gifFrameDelayCs`); GIF keeps `saveOptions/gifFrameDelayCs`, and editing either key's default updates the other at its precision. GIF's direct centisecond parser and byte canary remain unchanged. WebP loop count 0 means forever; positive values count total plays. Imported/chosen counts live in document metadata `webp.loop_count`, not global settings or PSD/recovery serialization. New documents default to forever. Scripts use `doc.exportAnimatedWebp`; ordinary scripted WebP saves remain flat.

- Codec isolation: libwebp is statically linked on desktop and wasm, with private symbol names generated by `scripts/dev/generate-webp-symbols.py`. Two upstream function-like macros need namespace-only edits, recorded in `src/formats/libwebp/PATCHY.md`. Update the pinned sources, regenerate that header, and audit defined globals against Qt when upgrading. Tools and codec threads are disabled. No FFmpeg is used for WebP.

The Save As WebP, JPEG XL and GIF dialogs build their timing rows with `create_animation_timing_controls` and the Export section's Transparency group with `add_transparency_choice` (image_save_options_dialog); Export for Web uses the same two helpers ([web-export.md](web-export.md)).

## Frames and layers named "all"

Every animated writer (GIF, WebP, JPEG XL, APNG; the export actions, Save As animation, Export for Web and the `doc.exportAnimated*`/`animate` script paths) and the Animation Preview window take their frames from `animation::animation_frames` and draw each through `animation::animation_frame_stack` (`src/formats/animation_frames.{hpp,cpp}`, Qt-free; local card local-030, November 6, 2026). Rules:

- A sibling list is read in clipping units: a layer that is not clipped plus the clipped layers directly above it (a clipped group starts its own unit, as `effective_clip_base` reads it). A clipped layer is never a frame of its own; it is drawn with its base in every frame that draws the base.
- The base's name decides: it matches "all" when, trimmed and with any trailing time token removed, it equals "all" ignoring ASCII case ("All", " all ", "all 0.5s").
- A layer named "all" that is not a group is shared: it is drawn in every frame at its own place in the stack (below the frames a background, above them an overlay), with its own opacity, blend mode, effects, mask and clipped layers. It is not a frame and adds no time; its time token is ignored.
- A group named "all" is a frame container: the group is not a frame, each unit inside it is one, in the same top-first order, and the frames are drawn inside a copy of the group holding only that frame plus the group's shared children, so the group's opacity, blend mode, effects, mask, smart filters and the layers clipped to the group apply to every one of them. Each child keeps its own time token. A normal group inside it is one frame; an "all" group inside it expands again; a child named "all" is shared, drawn in every frame of the whole animation inside the group. An "all" group whose children are all named "all" has no frames and is therefore a shared group (the way to share a background made of several layers).
- Every other unit (any layer, or a group not named "all") is one frame, as before. Only top-level units and units inside "all" groups are considered.
- Visibility: a hidden unit is neither a frame nor drawn; a hidden "all" group contributes nothing. The preview's "Play hidden layers" also plays hidden frames (a hidden "all" group's children included), but never draws a hidden shared layer. The preview shows a frame by showing it and its "all" groups, hiding the other frames and leaving shared and clipped layers as they are (it saves and restores the visibility of every top-level layer and every layer inside an "all" group).
- Save As / Export offer the animation choice for two or more top-level layers, or for one "all" group holding two or more frames (`offers_animation_frames`, main_window_files.cpp); the choice is enabled when the frame list is not empty. Export trim uses the union of the full frames, shared layers included. A document with no "all" name and no clipped top-level layer renders exactly as before (one top-level layer per frame through the same scratch-canvas render).

The user-facing notes say it in one sentence ("A layer named "all" is drawn in every frame instead of being one, and each layer inside a group named "all" is its own frame."): the Animation Preview note (`animationPreviewHintLabel`), the explanation `create_animation_timing_controls` gives every GIF, WebP, JPEG XL and APNG options dialog and Export for Web's Animation group, and the Export for Web "Animation from visible layers" tooltip. Translations keep the keyword `all` untranslated. Save As options dialogs (not export forms, which `finish_export_dialog_size` sizes) grow to the height their wrapped labels need at the dialog's width (`finish_options_dialog`), so a longer note or translation never clips.

Tests: core `animation_frames_*` (`tests/core/animation_frames_tests.cpp`), UI `ui_animated_export_all_layers_*`, `ui_animation_preview_plays_all_layers` and `ui_animation_texts_explain_all_layers_in_every_language` (every shipped language: the note is there and no label clips in the preview or the GIF, WebP, JPEG XL and APNG dialogs; English and German captures) (`tests/ui/layer_panel_organization_tests_animation.cpp`).

Export for Web plays an animated GIF, WebP, JPEG XL or PNG in its preview from the encoded file's
frames beside the source frames of `for_each_animation_export_frame`, the frame list every
animated writer uses ([web-export.md](web-export.md#animation-playback)).

## Animation preview window

The film button (`layerAnimationButton`) and Image > Animation Preview (`imageAnimationPreviewAction`, command `image.animation_preview`, unbound; GitHub issue 512; `ui_image_menu_opens_animation_preview`) toggle `AnimationPreviewWindow` (`src/ui/animation_preview_window.{hpp,cpp}`, the TilePreviewWindow pattern). It reads top to bottom (GitHub issue 198), each group a grid with its label and field on the first row, the options under the field and its buttons at the right of the last row, 6 px further below the options than they sit from each other (GitHub issue 198 follow-up): a Playback group ("Default frame delay", then "Ignore delays in layer names", "Play hidden layers", and the frame counter beside Play), then a "Layer names" group ("Frame delay", "Apply to all layers", Set Time and Remove Time). Both delays are one control each, the Preferences interface-scale pattern: a `DelaySecondsSpinBox` (type seconds, unit optional; - and + step 0.1 s; text it cannot use, empty, non-numeric or over the maximum, puts the last value back) with a chevron presets drop-down against it (0.05/0.1/0.2/0.5/1 s, the held value ticked). Both fields stretch (at least "9999.19 s" wide) so each drop-down ends at the right edge of the buttons below, and the two labels share a width so the fields start at the same x (`ui_animation_preview_ignores_name_delays_and_plays_hidden_layers` checks both, also with the window widened). Play cycles the visible frames from top to bottom, hiding the others (frames and "all" layers: [Frames and layers named "all"](#frames-and-layers-named-all)); "Play hidden layers" adds the hidden frames (toggling it mid-play restarts playback). A trailing seconds token overrides the default unless "Ignore delays in layer names" is on. Both checkboxes are preview-only: export keeps visible layers and name times. They persist in `animationPreview/ignoreNameDelays` and `animationPreview/playHiddenLayers`. The field edits shared `saveOptions/animationFrameDelayMs` (whole milliseconds) and rounds the legacy GIF default to centiseconds. Stop, closing the preview, a tab switch, or document close restores captured visibility. MainWindow calls `stop_playback_for` in `activate_document_canvas` while the outgoing document is active and early in `close_document_session`, before the save prompt. Playback mutates visibility without undo or dirtying the session. Per-frame updates use `sync_layer_row_visibility_indicators`; a full `refresh_layer_list` runs once at stop. Tests: `ui_animation_preview_plays_visible_layers_and_restores`, `ui_animation_preview_ignores_name_delays_and_plays_hidden_layers`, `ui_animation_preview_stops_on_tab_switch_and_close`; the window is in `ui_offscreen_dialog_sweep_is_themed_in_both_schemes`.

The "Layer names" group edits the name tokens: Set Time renames the selected (else active) layers, or every top-level layer with "Apply to all layers" (`animationPreview/applyToAllLayers`), to end with the group's own delay field (`animationSelectionTimeSpin`) (replacing any existing token, via `gif::strip_layer_name_delay_token` plus `format_delay_seconds_token`), Remove Time strips the token, and a name that is nothing but a token keeps it. Both go through `MainWindow::set_selected_layers_frame_time` as one undo snapshot ("Set frame time"/"Remove frame time"), and the panel stops playback (with restore) before invoking it so the snapshot never captures a preview frame's visibility; a no-op click pushes nothing and reports through `show_status_error`. Pinned by `ui_animation_preview_sets_and_removes_frame_time_names` and `ui_animation_preview_sets_and_removes_frame_time_on_all_layers`.
