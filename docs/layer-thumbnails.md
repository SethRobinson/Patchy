# Layer thumbnails

How the Layers panel draws its row thumbnails and the settings that shape them. The rest of the panel, the thumbnail menus and Ctrl-click selection loads included, is in [layer-panel.md](layer-panel.md).

## Tiles and bounds

In document-mapped mode (the zoom preference below turned off), layer-panel previews show the whole document, shaped like it and centered in a fixed slot, a smaller layer at its own position on checkerboard. `thumbnail_tile_size` and `thumbnail_preview_space` do the fitting and the document-space mapping for the content, mask, vector-mask, and Smart Filter mask previews, so the previews in one row share a shape. Folder, text, and adjustment thumbnails are glyphs drawn in 28 px coordinates scaled to the tile, and stay square. Because the tile depends on the canvas extent, `LayerThumbnailCacheEntry` keys on it alongside the layer revision and `refresh_layer_thumbnails` restamps every row when it changes. `layerTargetActive` frames the slot rather than the pixmap, so switching the edit target is a property flip with no thumbnail rebuild (`ui_layer_thumbnails_preview_the_whole_document`). Every content (`layerThumbnailSlot`, false for folder and artboard glyphs), layer mask and vector mask slot draws a 1 px QSS ring in `layer_thumbnail_outline` (darker than the row in Dark, a mid gray in Light), so white, transparent and letterboxed tiles read as one square shape; the active target's 2 px `accent_bright` border replaces it (#514, `ui_layer_thumbnail_slots_draw_outline_ring`). The `view/zoomLayerThumbnailsToContent` preference (default on, Preferences > Application) swaps the document space for a per-layer crop: the visible-alpha extent (revision-cached in core), else the declared pixel bounds, else the raster mask bounds. `MainWindow::layer_thumbnail_crop` gates it; content and Smart Filter mask previews share the crop, a layer mask frames its rect, a vector mask the canvas (`raster_mask_thumbnail_crop`), glyphs stay exempt, and toggling the preference clears `layer_thumbnail_cache_` because the mode is a shape input the revision keys do not track (`ui_layer_thumbnails_zoom_to_content_preference`).

Thumbnail size (#386): the Thumbnail Size submenu (`layerThumbnailSize*Action`) on the pixel, layer mask and vector mask thumbnail menus (all through `add_layer_thumbnail_view_menus`, with Thumbnail Display) picks None, Small, Medium (28 px, default) or Large, saved as `view/layerThumbnailSize` (tokens, tile and row heights: `src/ui/layer_thumbnail_size.hpp`). None builds no content tile and keeps masks Small, so at None (only) the row and Background menus end with the submenu too, the way back (#481). A change clears the cache, rebuilding (`ui_layer_thumbnail_size_menu_resizes_rows_and_persists`). Right under it, the Thumbnail Display submenu (`layerThumbnailDisplayMenu`: `layerThumbnailBoundsLayerAction` Layer Content, `layerThumbnailBoundsDocumentAction` Whole Document) sets the zoom preference above through `set_zoom_layer_thumbnails_to_content`, which Preferences also calls, so both stay in step (#481; tested in `ui_layer_thumbnails_zoom_to_content_preference`).

## Layers panel settings gear

The gear at the right end of the Layers title row (`layersPanelSettingsButton`, tooltip "Layers panel settings", #511) pops up `layersPanelSettingsMenu`: Customize Layers Panel... (`layersPanelCustomizeButtonsAction`, Customize Tool Palette on its Layers Panel tab, [tool-palette.md](tool-palette.md)), a separator, then Thumbnail Size and Thumbnail Display. The menu is built once by `add_layer_thumbnail_view_menus`, so its submenus hold the same `layerThumbnailSize*Action` and `layerThumbnailBounds*Action` the thumbnail menus show and a pick ticks in both; the submenu titles are bound translations and `aboutToShow` re-reads the size and zoom settings (Preferences can change the zoom). The thumbnail menus keep their submenus (Seth, October 29, 2026). The button is a `PanelSpec::header_widget` like the Color gear ([right-docks.md](right-docks.md)) and shares its window sheet rule (`main_window_theme.cpp`); the title row's right-click menu stays the panel list, as on every panel. Coverage: `ui_layers_panel_gear_opens_layer_button_customize`.
