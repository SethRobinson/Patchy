# GEGL filters

Patchy offers GEGL's image filters (GEGL is the Generic Graphics Library GIMP builds most of its Filters menu from) under Filter > GEGL Filters, one submenu per GEGL category, from Patchy's own build of GEGL ("Bundled GEGL"); GIMP is never needed or used. They run in Patchy's own filter dialog, with its canvas preview and in-dialog preview, progress and Cancel, and as one undo step. Legal boundary (binding): [legal-licensing.md](legal-licensing.md#gegl-operations-through-a-helper); sources consulted: [gegl-provenance.md](gegl-provenance.md). Status: on the local branch `desk/i567-gimp3-plugins`, not in main. The branch's GIMP 3 plug-in bridge, and the use of an installed GIMP's GEGL, were removed on November 2, 2026 (Seth); they are in the branch's history before that commit.

## Parts

| Part | Where | What |
|---|---|---|
| Helper | `src/plugins/gegl/host/main.cpp` (`patchy-gegl-host`) | Loads Patchy's own GEGL, babl and GLib at run time; `--list` prints every operation and its settings as JSON, `--run` runs one operation on the pixels from stdin |
| Patchy side | `src/ui/gegl_filters.{hpp,cpp}` | Finding the library, the offered set (`gegl_operation_offered`), GEGL settings as Patchy filter parameters, a run through the helper |
| MainWindow | `src/ui/main_window_gegl_filters.cpp`, `apply_filter` in `main_window_filters.cpp` | The scan at startup, the menu, the registry `apply_filter` takes for `gegl.*` ids |

Only the helper loads GEGL. Its declarations of GEGL, babl and GLib functions and structs are its own, from the installed public headers (`NOTICE-THIRD-PARTY.md`); nothing is linked at build time.

## Bundled GEGL

Decided November 2, 2026 (Seth asked for Patchy's own GEGL, independent of GIMP and its versions). `bundled_gegl_library` looks beside the program (`<program folder>/gegl` on Windows and in build trees, `Contents/Frameworks/gegl` in the macOS bundle, `../lib/patchy/gegl` in the AppImage and other installed Linux builds, the Flatpak's `/app/lib`); a build without it offers no GEGL filters (the menu says so). Every desktop package ships it with `patchy-gegl-host`: the Windows x64 and ARM64 installers and zips, the macOS DMG, the Flatpak and the AppImage. The web version has none (no separate processes there).

- Built from gimp.org's GEGL 0.4.72 and babl 0.1.128 release tarballs (SHA-256 pinned) with every optional dependency off (`-Dauto_features=disabled`: no PDF, raw, SVG, text, video or TIFF code) and without the operations `scripts/dev/gegl/common.sh` names (`PATCHY_GEGL_DROPPED`: each removed from GEGL's build list by file name before the build, the source files never opened; "Legal review"), by `scripts/dev/gegl/build-gegl-msys2.sh` on Windows (MSYS2 CLANG64 for x64, CLANGARM64 for ARM64). It stages `.deps/gegl/0.4.72/<platform>/{bin,lib/gegl-0.4,lib/babl-0.1,share/locale,licenses}`; `cmake/patchy_gegl.cmake` finds it and copies it once into `<build>/gegl` (`patchy_gegl_bundle`); `build-release.bat` refuses a package without it and `package-selftest.js` runs Gaussian Blur from the packaged app.
- Shipped: `libgegl`, `libbabl`, the libraries they import (followed through the import tables with `objdump`: GLib's five, json-glib, libffi, PCRE2, libiconv, libintl, zlib), the operation modules `gegl-common`, `gegl-common-cxx`, `gegl-generated`, `gegl-common-gpl3` (GPL-3, decided November 2, 2026; with their `-x86_64-v2`/`-v3` builds, which GEGL picks on newer CPUs), `gegl-core`, babl's extensions minus `cairo`, GEGL's catalogs for Patchy's languages, and every license with `licenses/SOURCES.txt` (versions, tarball URLs, MSYS2 packages and their source packages, the removed operations, where the source is). Not shipped: file loaders and savers (and with them libjpeg and libpng), transforms, seamless clone, vector fill, the meta JSON operations.
- Windows x64: 115 files, 19.0 MB, 7.9 MB in a zip; 117 filters offered (43 GPL-3).
- Windows ARM64 (built natively under CLANGARM64 on the ARM64 host, then copied into this PC's `.deps` for the cross-built package): 71 files, 12.7 MB, 5.2 MB zipped (no CPU-variant modules). MSYS2's `ldd` hangs there, which is why the script reads import tables.
- Linux: `scripts/dev/gegl/build-gegl-linux.sh` builds the same way inside the Flatpak SDK of Patchy's manifest (`org.kde.Sdk`, whose GLib and json-glib the bundle uses, so they are not staged) into `.deps/gegl/0.4.72/linux-x64` for build trees: 95 files, 12 MB, 5.0 MB compressed. Patchy's own Flatpak builds babl and GEGL as manifest modules from the same tarballs (`--libdir=lib`, the licenses into `/app/share/licenses/com.rtsoft.patchy`, `cleanup` removing what the Windows bundle leaves out) and finds `/app/lib/libgegl-0.4.so.0`.
- AppImage: `scripts/dev/gegl/build-gegl-appimage.sh` builds inside the AppImage's Ubuntu 22.04 container (`build-in-container.sh` runs it when `.deps/gegl/0.4.72/linux-x64-appimage` is missing; the `linux-appimage` presets set `PATCHY_GEGL_BUNDLE_DIR` there, never the Flatpak-SDK bundle). The host's GLib and json-glib cannot be counted on, so, as on macOS, GLib (PCRE2 from its subproject), json-glib, babl and GEGL are built from the locked tarballs; libffi is Ubuntu's (MIT); glibc, libstdc++ and zlib are the host's. RUNPATHs (`$ORIGIN`, `$ORIGIN/..` for the module folders) and an `ldd` check keep it self-contained, and it passes the AppImage's ABI audit. `cmake --install` puts it in `usr/lib/patchy/gegl`, which `build-in-container.sh` keeps away from linuxdeploy (it would copy GLib into `usr/lib` and rewrite the RUNPATHs); the AppImage smoke check lists the filters and runs one. 94 files, 16 MB, 6.3 MB compressed; GEGL 0.4.72 on Ubuntu 24.04 through a FUSE mount: 116 filters, November 2, 2026.
- macOS: `scripts/dev/gegl/build-gegl-macos.sh` builds everything shipped from source for macOS 12.0 (Homebrew's libraries target the macOS they were built on): gettext's libintl, GLib (PCRE2 from its subproject; libffi and libiconv are the system's), json-glib, babl, GEGL; every library is renamed `@rpath/<file>` with `@loader_path` rpaths and checked to name no Homebrew path. `.deps/gegl/0.4.72/osx-arm64`: 61 files, 11 MB, 3.8 MB zipped. The app bundle carries the libraries in `Contents/Frameworks/gegl/lib`, with the module folders renamed `gegl-modules` and `babl-extensions` (codesign takes a dotted folder name inside `Frameworks` for a bundle and refuses the whole app), and the catalogs and licenses in `Contents/Resources/gegl` (data does not belong among code); `prepare_helper` finds either layout and passes the catalog folder as `PATCHY_GEGL_LOCALE_DIR`.
- Off Windows the helper is started with `GEGL_PATH`/`BABL_PATH` at the module folders and, on Linux, `LD_LIBRARY_PATH` at the library folder (`prepare_helper`; the build-tree bundle has no RUNPATHs). macOS needs no loader variable: the `@rpath` names resolve; Windows GEGL finds its modules relative to its DLL, and the helper puts the bundle's `bin` first on its DLL search path and `PATH`, since GEGL loads its operation modules later and they find the other DLLs there. `GEGL_THREADS` is set to the core count unless already set.
- macOS signing: `make-dmg.sh` signs each bundled library with Patchy's identity, then the app (`--deep`, hardened runtime); the helper gets no entitlements. Checked November 2, 2026 with the Developer ID identity and a hardened helper: with no entitlements it lists 188 operations, runs Cartoon and reads the German catalog, the same as with `disable-library-validation` and `allow-dyld-environment-variables` (it loads only same-team libraries, and ignores `DYLD_LIBRARY_PATH`, which it no longer needs). Before the layout above, `codesign --deep` failed on `babl-0.1`.

## Sources

The licenses (GEGL's GPL-3 module, the LGPL of the rest) require the complete corresponding source wherever the binaries are offered. `scripts/dev/gegl/sources.lock` lists every source archive behind any bundle (file, SHA-256, URL): GEGL and babl, what the macOS script builds (GLib, its PCRE2 subproject and the wrap's build files, json-glib, gettext), and MSYS2's source packages (PKGBUILD, patches, upstream tarball) for each Windows library. The build scripts stop when an archive they used, or an MSYS2 package they staged, is not in the lock (the MSYS2 script downloads the missing source package into `.deps/gegl/sources` and prints its line; MSYS2 keeps old source packages). `scripts/release/make-gegl-sources.ps1` (run by `build-release.bat` after both Windows packages) packs every locked archive, checked against its SHA-256, with `scripts/dev/gegl/` and the Flatpak manifest into `build\package\PatchyGeglSources.zip` (about 53 MB); `publish-github-release.ps1` attaches it to each release and links it in the notes, `upload-windows-to-rtsoft.bat` mirrors it to `rtsoft.com/files/`, and each bundle's `SOURCES.txt` (the Flatpak's `gegl-SOURCES.txt`) points to both. Patchy's own source, the helper included, is the release tag on GitHub. A new GEGL, GLib or MSYS2 package version means new lock lines in the same change.

## Legal review

Binding rule: [legal-licensing.md](legal-licensing.md#gegl-operations-through-a-helper). Every operation "What is offered" admits from GEGL 0.4.72 with its GPL-3 module was reviewed on November 2, 2026, from its own description (GEGL's source is never read): by algorithm class against the recorded patent families, as the G'MIC triage did ([patent-research-gmic.md](patent-research-gmic.md#family-triage-of-the-offered-filters-2026-10-20)), plus a patent search (USPTO full text, Google Patents; inventor, assignee and claim-term queries; US only, no EP Register search) for each family the records did not cover.

- **Built without** (`PATCHY_GEGL_DROPPED`, so their code never ships, and also in `excluded_by_name`): Median Blur (the Surface Blur rule allows only one window histogram updated one value at a time, and GEGL's method cannot be checked; US 8594445, US 7920741), Focus Blur (a per-pixel blur-radius mask, the Blur Gallery family), Red Eye Removal (a whole-region redness scan; Patchy's Red Eye tool is the reviewed one). Inpainting, seamless clone and healing are not in the modules shipped.
- **Left out of the menu, as not useful:** Absolute, Unpremultiply, Tile, Rectangle, and Drop Shadow (it builds Median Blur and Translate internally, so its offset and grow do nothing here; the layer style does it).
- **Vibrance is offered:** it was left out for Apple US 8638338 (in force to 2032-03-22) until the claim read of 2026-11-02 ([patent-research-adjustments.md](patent-research-adjustments.md)) found it clear: probed as a black box, it adds about the same chroma to every pixel, with no protected color region and no reference colors.
- **Cleared by search:** Fattal 2002 tone mapping (Yissum US 7305144 reads on it, expired 2024-12-27), Shadows-Highlights (Adobe's Shadow/Highlight family US 7412105, US 7853096, US 8260080 expired; the Poisson adjustment patents US 7248745 / US 7657119 past term; no later continuation), Bloom (Microsoft US 7202867 and US 7414625, threshold-blur-add, expired about 2024-03; active ones need depth buffers, frame reuse or trained shaders), Long Shadow (Adobe US 7764286 needs differently oriented shadow segments, Google US 8643678 a 3D projection), Color to Grayscale and STRESS (Adobe US 7706606, active to about 2029, needs color clusters mapped globally, not random spatial sampling), SLIC and Waterpixels (no patent; EPFL's US 10229337 claims a different method), Domain Transform, Mantiuk 2006 and Reinhard 2005 (no patent on the methods).
- **Within recorded boundaries:** Linear, Circular and Zoom Motion Blur (one straight user kernel, one polar transform), Bilateral Filter (direct range weights, no histogram), Unsharp Mask and High Pass, Noise Reduction, DCT Denoise and SNN Mean (no patch search), Stretch Contrast and Color Enhance (whole-image statistics), Lens Flare and Supernova (GIMP's own 1990s designs, not Photoshop's presets), the rest plain point, convolution, noise, render or geometric operations, most of the GPL-3 module ports of GIMP plug-ins first released from 1997 to 2004 (Cartoon, Photocopy, Softglow, Cubism, Mosaic, Ripple, Waves, Emboss, Color to Alpha and Value Propagate among them; Color to Alpha's later thresholds are point operations).
- A new GEGL version, or an operation it adds, needs the same check before it ships.

## GPL-3 operations

GEGL loads its GPL-3 operations (Cartoon, Cubism, Emboss, Ripple, Plasma, Shadows-Highlights and others: 43 offered from GEGL 0.4.72) only for a program that sets GeglConfig's `application-license` to "GPL3", as GIMP does. Patchy passes `--gpl3` and the helper sets it before `gegl_init` (afterwards GEGL reloads every module and warns about duplicate types). Patchy's own GEGL ships the module (decided November 2, 2026), so its source duty applies ("Sources").

## The scan

At startup (not offscreen) and on a language change, a worker lists the operations (`scan_gegl_filters`). The helper's list is cached in `<AppData>/gegl-filters/operations.json` under a key of the cache version, GEGL's library file (path, size, time), the helper file and the language, so a launch with nothing changed starts no helper. Bump `kCacheVersion` when the list's shape changes.

## What is offered

`gegl_operation_offered`: a `gegl:` operation with an output pad and no aux pad, and either an input pad (a one-layer filter) or the `render` category (Plasma, Solid Noise, Perlin, Simplex and Cell Noise, Sinus, Spiral, Diffraction Patterns, gradients, Grid, Bayer Matrix, GEGL's Fractal Explorer: the helper links no input and the result replaces the layer inside the selection), at least one category, none of the excluded categories (core, programming, hidden, meta, json, video, compositors, blend, transform, vector, svgfilter, input, output, debug), not excluded by name (`excluded_by_name`: the "Legal review" names, any inpainting, seamless clone, red eye or healing name, and the operations not useful on a layer), and no setting of a kind Patchy cannot hold (text, paths, curves, buffers, pointers): text settings are file paths, matrices, the graph language of `gegl:gegl` (which could load files) or `gegl:text`'s words. Patchy's GEGL 0.4.72: 117 offered (43 GPL-3).

Ids are `gegl.` plus the operation name without `gegl:` (`gegl.gaussian-blur`). They live in a registry of their own (`GeglFilterScanResult::registry`), never in `filters_`: Smart Filters, Saved Looks, recipes and PSD output never see them, because another machine may lack the operation. Last Filter repeats one in the session.

## Settings

The helper reports each property from GEGL's own description of it (`gegl_operation_list_properties`): name, label, help, default, limits, the UI range of GEGL's own param specs, `unit` and choices. `parameter_for` maps them:

- double and float: Double, the limits clamped to plus or minus one million, the UI range as the slider range, the step from GEGL's digits.
- int, uint and seed: Integer; a seed gets the Randomize button.
- bool: Boolean. enum: Option, the choice nick as the value and GEGL's label as the text.
- `unit` pixel-distance or pixel-coordinate: pixels that scale with the in-dialog preview (`FilterSpatialScale::Pixels`); degree: degrees.
- color: an Option of Default (GEGL's own color, nothing sent), Foreground Color, Background Color, Black and White (`kColorChoices`, Patchy's existing data texts); the colors are the invocation's, captured when the filter starts. Operations with one include Vignette, Color to Alpha, Color Overlay and Supernova.
- text and anything else: the operation is not offered (see What is offered).

An operation without a shown setting applies at once, without a dialog. Titles, setting labels, help and choice labels are GEGL's own, translated from GEGL's catalog (`gegl-0.4.mo`, in the bundle for Patchy's languages): Patchy starts the scan with `LANGUAGE` set to its language and the helper asks libintl's `dgettext` (GLib's `g_dgettext` declines when the program has no catalog of its own). Three things make that work everywhere: the helper sets `LC_MESSAGES` from the environment (falling back to `en_US.UTF-8`, then `C.UTF-8`) because gettext ignores `LANGUAGE` in the "C" locale a program starts in, and only that category so the numbers it parses keep their notation; off Windows it binds `gegl-0.4` to `<library folder>/../share/locale`, since GEGL is bound to its build machine's folder; and it asks for UTF-8 (`bind_textdomain_codeset`), since Windows libintl otherwise answers in the ANSI code page. A language change lists the operations again. GEGL's categories are not in its catalog: `gegl_category_label` names the 18 that GEGL 0.4 offers through Patchy's own catalog (context `GeglFilters`) and capitalizes any other.

## A run

`run_operation` sends `op`, `size`, `format`, one `set` line per shown setting and `end`, then the pixels tightly packed, and reads the same bytes back. Formats: `R'G'B'[A] u8`, `R'G'B'[A] u16` and `RGB[A] float` for Patchy's linear 32-bit; other color modes are refused. Every depth runs natively: `deep_filter_support` reports `gegl.` ids as Native. Every run starts the helper (about 0.3 s on Windows before the filter itself) on the worker that asked; the workers have no event loop, so the write and the wait go through `waitForBytesWritten` and `waitForFinished` in 100 ms steps, checking Cancel each time (Cancel kills the helper). `PATCHY_GEGL_TRACE=1` logs each run's steps on stderr.

## Scripting

`patchy.gegl.filters()` (`ScriptGeglObject`, `ScriptEngineHost::gegl_filter_list` in `script_gegl_filters.cpp`, scans on first use) lists `{id, name, category, description, parameters}`, each parameter `{name, label, type, default, minimum, maximum, choices}` with the permanent type tokens `integer`, `number`, `boolean`, `choice`. `layer.applyFilter` takes a `gegl.` id and routes it to the GEGL registry (`apply_filter_to_layer`); parameters are keyed by GEGL's property name, a color by its choice value. Record: [scripting-api-changes.md](scripting-api-changes.md).

## Tests

`ui_gegl_filters_list_and_apply_if_available` (tests/ui/gegl_filter_tests.cpp; skips in a build without the bundle, which must then offer nothing): the scan, Gaussian Blur's mapped settings, Cartoon (GPL-3) offered, the legal, usefulness and kind exclusions (Median Blur, Focus Blur, Seamless Clone, Red Eye Removal, Absolute, Unpremultiply, Tile, Rectangle, Drop Shadow, Crop, Over, Text, PNG Load), Shadows-Highlights, SLIC, Waterpixels and Vibrance offered, Simplex Noise as a render operation, runs straight through the registry at 8, 16 and 32 bits, Color Overlay in the foreground color, German labels, the menu entry, a run through `apply_filter` and its undo, script listing and `applyFilter`, the Unsharp Mask and Vignette dialogs (saved to `test-artifacts/gegl-unsharp-mask-dialog.png` and `gegl-vignette-dialog.png`; Vignette shows a color choice) cancelled with the layer unchanged, the menu and its Blur submenu (`gegl-filters-menu.png`, `gegl-filters-blur-menu.png`), and Search Commands finding Bloom. `ui_gegl_bundled_filters_all_run` (skips without the bundle) runs every offered filter at its defaults on a 48 by 32 gradient and fails on any error or size change; it prints the filters the gradient leaves unchanged (identities at their defaults, such as Levels, Exposure, or a shadow under an opaque layer). It passed on Windows x64 and ARM64, macOS and Linux with 116 filters (November 2, 2026). `package-selftest.js` checks that a package offers Cartoon and not Median Blur.
