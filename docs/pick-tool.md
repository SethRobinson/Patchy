# Pick tool (Eyedropper)

The Pick tool (`CanvasTool::Eyedropper`, labeled "Pick") and the paint tools' temporary Alt eyedropper. Overlay geometry and painting live in `src/ui/eyedropper_sample_overlay.cpp`, free of CanvasWidget so tests reach them directly.

## Picking and options

A click sets the foreground color, Alt+click the background (GitHub issue 150; `color_pick_to_background_`, `set_background_color_picked_callback`). The paint tools' Alt eyedropper (`tool_uses_alt_left_for_color_pick`) always sets the foreground.

Options (GitHub issue 151; labels Size and Layer since issue 409): Size (`eyedropperSampleSizeCombo`: Point Sample, 3/5/11/31/51/101 by N Average; `tools/eyedropperSampleSize`, odd sides 1 to 101) and Layer (`eyedropperSampleLayersCombo`, GitHub issue 321: Current Layer, Current & Below, All Layers (default), All Layers No Adjustments, Current & Below No Adjustments; `SampleLayers` in core/layer_tree.hpp, token in `tools/eyedropperSampleLayers`; without it the pre-321 bool `tools/eyedropperSampleAllLayers` decides; saves still write it). MainWindow's `current_eyedropper_*` mirrors reach every canvas and the Alt eyedropper. An average is alpha-weighted over the square clipped to the document (`eyedropper_sample_rect`, shared with the outline below). All Layers reads the displayed composite (`compose_document_rect`; fully transparent gives black like a point pick). Current Layer reads the active pixel layer (`active_layer_sample_region`, mask and opacity in alpha); a transparent spot keeps the color, a non-pixel layer warns once per gesture. The other three render only the sample square (`qimage_from_document_rect_with_hidden_layers`) without `sample_layers_excluded_ids`: the later siblings at each level of the active layer's path, and all adjustment layers for No Adjustments; never a full composite per pick. Sets (`eyedropperSetsForegroundButton` / `eyedropperSetsBackgroundButton`, an exclusive pair that leads the bar unlabeled as its mode group, GitHub issue 322; `tools/eyedropperPicksBackground`, default Foreground) names the color a click sets; Alt inverts it for that click (`eyedropper_target_is_background`). The cursor's swatch badge (`eyedropper_target_cursor`) follows Alt; the paint tools' Alt eyedropper ignores Sets. Tests: `ui_eyedropper_*`, core `sample_layers_*`.

The bar reads `[Foreground] [Background] | Size [combo] Layer [combo] | [Show Sample Ring]` (GitHub issue 322, rule 1 of [options-bar.md](options-bar.md); the checkbox is issue 320). Test: `ui_pick_options_bar_groups_its_controls`.

## Sample square outline

With the Pick tool and an average Size, the canvas outlines the square a click averages (GitHub issue 319): `eyedropper_sample_rect` (shared with `pick_color`, so the outline is exactly the averaged pixels, clipped to the document), mapped to widget coordinates on whole document pixels, so it steps a pixel at a time with the pointer. It is drawn in the brush outline's cursor ink (dark outside, white inside), which is exempt from theme roles ([ui-conventions.md](ui-conventions.md)). Hidden for Point Sample, when the square is under `kEyedropperSampleOutlineMinScreenPixels` (4) screen pixels across, off the document, while space-panning, and for other tools. The hover position is tracked in `track_eyedropper_sample_outline` from every mouse move (pressed or not). Test: `ui_eyedropper_sample_outline_follows_the_pointer`.

## Sample loupe

While a pick is held, with the Pick tool or a paint tool's Alt eyedropper, the canvas shows a sample loupe (GitHub issue 320): Patchy's own take on a sample ring, with the same job of comparing the new color against the one it replaces. Show Sample Ring (`eyedropperShowSampleRingCheck`; `tools/eyedropperShowSampleRing`, default on; `current_eyedropper_show_sample_ring_` mirrored to every canvas) turns it off.

- **Lens.** A circle (`kSampleLoupeLensRadius`) showing the displayed pixels around the pointer (the composite, whatever Sample reads) enlarged on whole document pixels: `sample_loupe_view_rect`, the sample square plus three pixels of context, at least nine across (`sample_loupe_view_pixels`). A faint pixel grid shows when a cell is 5 screen pixels or more; the averaged square (or the single pixel of a Point Sample) is outlined in cursor ink. Outside the document the lens shows the canvas backdrop, transparency the checkerboard. Large averages shrink the view (smooth scaling below one screen pixel per cell).
- **Band.** Two arcs around the lens, split 20 degrees below the horizontal with 6 degree gaps: the larger top arc is the live sample (the target color as the pick updates it), the smaller bottom arc the target color when the press began (`sample_loupe_previous_color_`): the foreground, or the background when Sets or Alt picks into it. The paint tools' Alt eyedropper always targets the foreground.
- **Ink.** Every piece has a dark-plus-light border and a soft drop shadow, so it reads over any image; borders and the pixel grid are cursor ink, exempt from theme roles like every tool cursor ([ui-conventions.md](ui-conventions.md)). The sampled colors are user colors.
- **Placement.** Centered on the pointer, which it hides (`Qt::BlankCursor`; `update_tool_cursor` keeps it blank while `sample_loupe_hides_cursor_`). Near the viewport edge (rulers and scroll bars excluded, `sample_loupe_viewport`) it slides inward whole instead of clipping (`sample_loupe_geometry`), and a small ink crosshair then marks the pointer. Off the document a pick reads the screen and the loupe hides.
- **Cost.** Each pointer move reads only the lens square through `compose_document_rect` (a copy from the render cache when it is current); the paint draws that copy and never touches the document. A 32-bit composite goes through `display_image_from_deep_qimage` first, never QPainter on floats.

Tests: `ui_sample_loupe_geometry_stays_inside_the_viewport`, `ui_sample_loupe_shows_while_a_pick_is_held`, `ui_sample_loupe_lens_matches_the_canvas_at_every_depth`, `ui_eyedropper_options_bar_sample_controls`.
