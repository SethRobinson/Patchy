# Pick tool (Eyedropper) and Ruler

The Pick tool (`CanvasTool::Eyedropper`, labeled "Pick") and the paint tools' temporary Alt eyedropper. The Ruler shares Pick's palette slot; its section is at the end. Overlay geometry and painting live in `src/ui/eyedropper_sample_overlay.cpp`, free of CanvasWidget so tests reach them directly.

## Picking and options

A click sets the foreground color, Alt+click the background (GitHub issue 150; `color_pick_to_background_`, `set_background_color_picked_callback`). The paint tools' Alt eyedropper (`tool_uses_alt_left_for_color_pick`) always sets the foreground.

Options (GitHub issue 151; labels Size and Layer since issue 409): Size (`eyedropperSampleSizeCombo`: Point Sample, 3/5/11/31/51/101 by N Average; `tools/eyedropperSampleSize`, odd sides 1 to 101) and Layer (`eyedropperSampleLayersCombo`, GitHub issue 321: Current Layer, Current & Below, All Layers (default), All Layers No Adjustments, Current & Below No Adjustments; `SampleLayers` in core/layer_tree.hpp, token in `tools/eyedropperSampleLayers`; without it the pre-321 bool `tools/eyedropperSampleAllLayers` decides; saves still write it). MainWindow's `current_eyedropper_*` mirrors reach every canvas and the Alt eyedropper. The Magic Wand's Sample (`wandSampleSizeCombo`, GitHub issue 435) offers the same sizes but is a separate setting (`tools/wandSampleSize`, Point Sample by default; Seth chose separate over Photoshop's shared one): changing one never changes the other. The wand averages its seed with `wand_seed_color` (core/pixel_tools.hpp; Point Sample is the clicked pixel exactly). An average is alpha-weighted over the square clipped to the document (`eyedropper_sample_rect`, shared with the outline below). All Layers reads the displayed composite (`compose_document_rect`; fully transparent gives black like a point pick). Current Layer reads the active pixel layer (`active_layer_sample_region`, mask and opacity in alpha); a transparent spot keeps the color, a non-pixel layer warns once per gesture. The other three render only the sample square (`qimage_from_document_rect_with_hidden_layers`) without `sample_layers_excluded_ids`: the later siblings at each level of the active layer's path, and all adjustment layers for No Adjustments; never a full composite per pick. Sets (`eyedropperSetsForegroundButton` / `eyedropperSetsBackgroundButton`, an exclusive pair that leads the bar unlabeled as its mode group, GitHub issue 322; `tools/eyedropperPicksBackground`, default Foreground) names the color a click sets; Alt inverts it for that click (`eyedropper_target_is_background`). The cursor's swatch badge (`eyedropper_target_cursor`) follows Alt; the paint tools' Alt eyedropper ignores Sets. Tests: `ui_eyedropper_*`, core `sample_layers_*`.

The bar reads `[Foreground] [Background] | Size [combo] Layer [combo] | [Show Sample Ring]` (GitHub issue 322, rule 1 of [options-bar.md](options-bar.md); the checkbox is issue 320). Test: `ui_pick_options_bar_groups_its_controls`.

## Sample square outline

With the Pick tool and an average Size, the canvas outlines the square a click averages (GitHub issue 319): `eyedropper_sample_rect` (shared with `pick_color`, so the outline is exactly the averaged pixels, clipped to the document), mapped to widget coordinates on whole document pixels, so it steps a pixel at a time with the pointer. It is drawn in the brush outline's cursor ink (dark outside, white inside), which is exempt from theme roles ([ui-conventions.md](ui-conventions.md)). Hidden for Point Sample, when the square is under `kEyedropperSampleOutlineMinScreenPixels` (4) screen pixels across, off the document, while space-panning, and for other tools. The hover position is tracked in `track_eyedropper_sample_outline` from every mouse move (pressed or not). Test: `ui_eyedropper_sample_outline_follows_the_pointer`.

## Sample loupe

While a pick is held, with the Pick tool or a paint tool's Alt eyedropper, the canvas shows a sample loupe (GitHub issue 320): Patchy's own take on a sample ring, with the same job of comparing the new color against the one it replaces. Show Sample Ring (`eyedropperShowSampleRingCheck`; `tools/eyedropperShowSampleRing`, default on; `current_eyedropper_show_sample_ring_` mirrored to every canvas) turns it off.

- **Lens.** A circle (`kSampleLoupeLensRadius`) showing the displayed pixels around the pointer (the composite, whatever Sample reads) enlarged on whole document pixels: `sample_loupe_view_rect`, the sample square plus three pixels of context, at least nine across (`sample_loupe_view_pixels`). A faint pixel grid shows when a cell is 5 screen pixels or more; the averaged square (or the single pixel of a Point Sample) is outlined in cursor ink. Outside the document the lens shows the canvas backdrop, transparency the checkerboard. Large averages shrink the view (smooth scaling below one screen pixel per cell).
- **Band.** Two arcs around the lens, split 20 degrees below the horizontal with 6 degree gaps: the larger top arc is the live sample (the target color as the pick updates it), the smaller bottom arc the target color when the press began (`sample_loupe_previous_color_`): the foreground, or the background when Sets or Alt picks into it. The paint tools' Alt eyedropper always targets the foreground.
- **Ink.** Every piece has a dark-plus-light border and a soft drop shadow, so it reads over any image; borders and the pixel grid are cursor ink, exempt from theme roles like every tool cursor ([ui-conventions.md](ui-conventions.md)). The sampled colors are user colors.
- **Placement.** Centered on the pointer, which it hides (`Qt::BlankCursor`; `update_tool_cursor` keeps it blank while `sample_loupe_hides_cursor_`). Near the viewport edge (rulers and scroll bars excluded, `sample_loupe_viewport`) it slides inward whole instead of clipping (`sample_loupe_geometry`), and a small ink crosshair then marks the pointer. Off the document a pick reads the screen and the loupe hides.
- **Cost.** Each pointer move reads only the lens square through `compose_document_rect` (a copy from the render cache when it is current); the paint draws that copy and never touches the document. A 32-bit composite goes through `display_image_from_deep_qimage` first, never QPainter on floats.

Tests: `ui_sample_loupe_geometry_stays_inside_the_viewport`, `ui_sample_loupe_shows_while_a_pick_is_held`, `ui_sample_loupe_lens_matches_the_canvas_at_every_depth`, `ui_eyedropper_options_bar_sample_controls`.

## Drag cost

A held pick (the Pick tool or a paint tool's Alt eyedropper) is one of the drags whose queued pointer moves coalesce (`coalescing_drag_active`; "Drag move coalescing" in [interactive-previews.md](interactive-previews.md), GitHub #478): moves queued in one event-loop pass sample once, at the latest position, and the release picks where the pointer is. Each applied move samples, refreshes the loupe and reports the color; `set_picked_color` skips the report when the gesture already reported that same color, so a drag over flat color does not restyle the panels per move. MainWindow's color callbacks run per move, but the settings write (a file flush, once most of a move's cost) and the gradient preview refresh wait for the end of the pick: `color_drag_in_progress` covers both the Color panel's drag and `color_pick_active`, and the canvas's `set_color_pick_finished_callback` runs `finish_color_panel_drag`. `patchy_perf_tests pickdrag` times it on a 6000x4000, five-layer document; on MAPPY (October 2026) a move went from 11 to 15 ms to about 3 ms for every Size and Layer choice, and a 120-move burst from 930 ms to 30 ms applied one by one, 14 ms coalesced. Tests: `ui_pick_drag_coalesces_queued_moves`, `ui_pick_drag_saves_colors_on_release`.

## Ruler

The Ruler (`CanvasTool::Ruler`, GitHub issue 331) is the second member of the Pick flyout (`pickToolButton`): I selects Pick, Shift+I cycles the two (`tools.cycle.pick`), and the Ruler itself ships unbound (`tools.ruler`). Gestures (`src/ui/canvas_widget_ruler.cpp`): a drag draws the line, Shift keeping 45-degree steps; a press within 6 screen pixels of an end moves that end, within 4 of the line moves it whole; a press anywhere else starts a new line, and a click without a drag leaves no line. Alt+drag from an end adds a second leg from that end (the protractor), which becomes the vertex `start`. Ends sit on the pixel under the pointer (its top-left corner, so a press lands on the pixel it shows at any zoom); Esc mid-drag puts the line back.

The line (`RulerLine`, `src/ui/ruler_tool.hpp`) is a view overlay in document pixels kept per canvas: drawn only while the Ruler is the tool, never saved, never an undo step. A history restore of the same canvas size keeps it; another document or a size change clears it (`set_document_internal`). It is drawn in cursor ink (dark 3 px under light 1 px, ticks across the ends, an arc between protractor legs), exempt from theme roles like every tool overlay ([ui-conventions.md](ui-conventions.md)); the paint maps three points, nothing per pixel.

The bar reads `X Y W H A L1 L2 | [Straighten Layer] [Straighten Image] [Clear]` (labels `rulerReadoutX` ... `rulerReadoutL2`, plain text, refreshed by the canvas's ruler changed callback and `refresh_document_info`). X and Y are the start, W and H the first leg in document axes (down is positive), A the leg's angle counterclockwise from horizontal in (-180, 180], or with two legs the angle between them (0 to 180), L1 and L2 the leg lengths. Values follow `view/rulerUnits` through `format_ruler_readout`: positions in the unit at each axis's PPI (Percent of the document side), lengths in physical units converted per axis, in pixels with one decimal for Pixels and Percent.

Straighten (`MainWindow::straighten_with_ruler`) turns by `ruler_straighten_degrees`: the first leg goes to the NEAREST axis, so a line along a wall within 45 degrees of vertical stands it upright. Straighten Layer runs the Free Transform commit on the active layer (`CanvasWidget::straighten_layer`: rotation about the session box's center, the user's interpolation, one undo step renamed "Straighten Layer", the whole layer even with a selection active through `transform_ignores_selection_`); it is off without a line or for a position-locked layer, and Free Transform's own refusals reach the status bar. Straighten Image is the Crop tool's rotated crop (`crop_document`) with the box from `ruler_straighten_crop`: the largest rectangle of the canvas's shape that fits inside it when turned, centered, so no empty corners remain; one undo step. Both clear the line. No tool option is persisted (the inventory in [tool-options.md](tool-options.md)).
