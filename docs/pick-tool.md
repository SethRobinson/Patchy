# Pick tool (Eyedropper)

The Pick tool (`CanvasTool::Eyedropper`, labeled "Pick") and the paint tools' temporary Alt eyedropper. Overlay geometry and painting live in `src/ui/eyedropper_sample_overlay.cpp`, free of CanvasWidget so tests reach them directly.

## Picking and options

A click sets the foreground color; with the Eyedropper tool active, Alt+click sets the background color instead (Photoshop's convention, GitHub issue 150; `color_pick_to_background_`, reported through `set_background_color_picked_callback`). The paint tools' temporary Alt eyedropper (`tool_uses_alt_left_for_color_pick`) always sets the foreground. Test: `ui_eyedropper_alt_click_picks_the_background_color`.

Options (GitHub issue 151; the tool is labeled "Pick"): Sample Size (`eyedropperSampleSizeCombo`: Point Sample, 3/5/11/31/51/101 by N Average; `tools/eyedropperSampleSize`, odd sides 1 to 101) and Sample (`eyedropperSampleLayersCombo`: All Layers or Current Layer; `tools/eyedropperSampleAllLayers`, default All Layers). `current_eyedropper_*` mirrors in MainWindow, applied to every canvas; the paint tools' Alt eyedropper uses them too, as in Photoshop. An average is alpha-weighted over the square clipped to the document: All Layers reads the displayed composite (`compose_document_rect`, a fully transparent square gives black like a point pick), Current Layer reads the active pixel layer through `active_layer_sample_region` (mask and opacity in alpha); a transparent spot there leaves the color unchanged, and a non-pixel active layer warns once per gesture. Sets (`eyedropperSetsForegroundButton` / `eyedropperSetsBackgroundButton`, an exclusive pair that leads the bar unlabeled as its mode group, GitHub issue 322; `tools/eyedropperPicksBackground`, default Foreground) names the color a click sets, and Alt inverts it for that click (`eyedropper_target_is_background`, the Zoom tool's mode-XOR-Alt rule), so the default keeps Photoshop's Alt+click background pick. The Eyedropper cursor carries a swatch badge for that target (`eyedropper_target_cursor`), refreshed when Alt toggles; the paint tools' Alt eyedropper ignores Sets. Tests: `ui_eyedropper_sample_size_and_current_layer`, `ui_eyedropper_sets_option_and_alt_inverts`, `ui_eyedropper_options_bar_sample_controls`.

The bar reads `[Foreground] [Background] | Sample Size [combo] Sample [combo]` (GitHub issue 322, rule 1 of [options-bar.md](options-bar.md)). Test: `ui_pick_options_bar_groups_its_controls`.

## Sample square outline

With the Pick tool and an average Sample Size, the canvas outlines the square a click averages (GitHub issue 319): `eyedropper_sample_rect` (shared with `pick_color`, so the outline is exactly the averaged pixels, clipped to the document), mapped to widget coordinates on whole document pixels, so it steps a pixel at a time with the pointer. It is drawn in the brush outline's cursor ink (dark outside, white inside), which is exempt from theme roles ([ui-conventions.md](ui-conventions.md)). Hidden for Point Sample, when the square is under `kEyedropperSampleOutlineMinScreenPixels` (4) screen pixels across, off the document, while space-panning, and for other tools. The hover position is tracked in `track_eyedropper_sample_outline` from every mouse move (pressed or not). Test: `ui_eyedropper_sample_outline_follows_the_pointer`.
