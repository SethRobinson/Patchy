# Colors and Themes preferences page

Split from [theme-files.md](theme-files.md): Preferences > Colors and Themes, with its theme list, live previews, details panel, theme file buttons and the theme sound and effect switches.

## Preferences UI

Preferences > Colors and Themes (`main_window_preferences_themes.cpp`, page id `themes`; `PreferencesThemesPage` hands show_preferences its populate, commit and revert). The page's widgets are built with the dialog, but the themes are read on the page's first visit (`populate`), and then only as summaries: `load_theme_summary_by_id` reads a package's theme.json and decodes its backdrop (`ThemeAssets::summary`), enough for the row's name, subtitle and swatch. `ThemesPage::ensure_full_theme` loads a package in full when its row is shown in detail or applied (selection, the entry theme at populate, revert), so opening the page decodes one package, not all of them. A package that summarizes but fails its full load (a damaged zip entry, a limit only the full read checks) becomes a disabled "Could not be loaded" row with its error as the tooltip and in the details, and the previewed theme stays. `ThemeManager::set_custom_theme` asserts it never gets a summary. A commit or revert on a page never visited changes no theme.

- `preferencesThemeList` holds three sections: Dark and Light (Follow system, Dark, Light), Included themes (the bundled set), and Your themes (every `user_theme_ids()` id; the header only when there are any). Section headers carry no token and are not selectable. Each theme row carries its token in `Qt::UserRole` (`system`, `dark`, `light`, or `"custom:" + id`), a swatch drawn from the theme's own palette (and backdrop), and a subtitle: version and author when the theme has them, otherwise what it is, plus "Needs Patchy X" when `minPatchyVersion` is newer than this build. A theme that fails to load is listed, disabled, with its error as the tooltip.
- Selecting a row previews it live (`set_custom_theme`/`set_preference`, unpersisted); OK persists it (without a second apply when it is already showing) and every other way out reapplies the entry theme (a scope guard in show_preferences, so the stress-test path is covered too).
- The details panel shows a larger preview, the name, version, author, base scheme and what a package includes, the "needs a newer Patchy" note, the theme's own Run this theme's scripts box ([Theme scripts](theme-files-scripts.md#theme-scripts)), and last the description under "Theme description:" (both hidden without one; `ui_theme_description_parses_round_trips_and_shows_in_details`). Theme-supplied text reaches labels and message boxes only as `Qt::PlainText`: a theme.json name, author or description must never render as rich text.
- Selecting a theme whose `minPatchyVersion` is newer than this build warns once per dialog open (`themeNeedsNewerPatchyMessageBox`; not in unattended runs). Import asks before copying such a theme (`importThemeNeedsNewerPatchyMessageBox`).
- Buttons (all `#ifndef Q_OS_WASM`): Import Theme copies a chosen `.patchytheme` or `.zip` (validated by loading it first) into `user_themes_directory()` under its own name, de-duplicated, asks the script question for a package with scripts, and selects it; Export Theme writes `serialize_theme_to_json(theme(), active_color_scheme(), name)` from the live palette, opening in the themes folder with the shown theme's name suggested (`exportThemeFileDialog`), and a file saved inside that folder is listed and selected at once (the "copy a built-in, then edit it" path); Reload Themes rereads every theme and re-applies the selected row even when it did not move (the authoring loop); Delete Theme (only on a Your themes row; `preferencesDeleteThemeConfirm`) removes the file, or moves a package folder to the trash (`QFile::moveToTrash`, never a recursive delete) after clearing the theme if it is showing, then selects Follow system; Open Themes Folder; Export Theme Package writes `serialize_theme_package_zip` (theme.json from the live palette plus the shown package's options, info and files); Export Icon Template.
- Play theme sounds and Play theme effects commit on OK. Picking a theme row (click or arrow keys, not the list rebuilds of Import or Reload) also plays its startup sound through `play_theme_startup_preview`, gated on the box as shown rather than the stored setting (`ui_preferences_theme_row_plays_its_startup_sound`).
