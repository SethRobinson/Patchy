# Red Eye real-photo fixtures

Crops of flash photos with red-eye from Wikimedia Commons, used by
`ui_red_eye_real_photos_leave_no_red_fringe` (tests/ui/brush_engine_stroke_tests_healing_patch.cpp)
to check the Red Eye tool on real eyes (docs/healing.md, "Red Eye"). Each file is a PNG crop of the
decoded original, unchanged otherwise. Pupil centers (crop pixels) are listed in the test.
